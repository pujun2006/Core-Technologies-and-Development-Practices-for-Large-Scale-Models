使用 **PyTorch** 与 **Hugging Face transformers** 库实现文本生成模型，既可以直接加载现有预训练模型完成推理与微调，也可以基于 `nn.Module` 或 `PreTrainedModel` 从零搭建自回归 Transformer 结构。核心在于理解**自回归下一词预测（Next-Token Prediction）的数据对齐、损失计算与推理解码闭环**。

---

### 一、 核心实现路径：加载预训练模型 vs. 自定义搭建

在工程实践中，通常根据目标选择两条路线：

1. **基于 `transformers` 预训练模型（主流推荐）**
* 利用 `AutoTokenizer`、`AutoConfig`、`AutoModelForCausalLM` 直接加载现有模型权重与词表；
* 适合快速验证、领域微调（SFT）、对齐训练以及调用成熟的 `generate()` 解码流水线。


2. **基于 PyTorch 原生模块自定义实现**
* 通过 `nn.Embedding`、`nn.ModuleList`、`nn.MultiheadAttention`（或手写 Q/K/V 缩放点积注意力 + 因果掩码）与 `nn.Linear` 搭建解码器层；
* 适合教学理解底层张量变换、研究新型注意力/位置编码或定制极简实验模型。



---

### 二、 训练与微调的关键细节（Next-Token Prediction）

无论是从零训练还是做监督微调（SFT），自回归生成模型的本质都是最大化序列联合概率：

<img width="429" height="105" alt="29fd6fa2-17fa-4ac8-8dce-b9d1f024cd9f" src="https://github.com/user-attachments/assets/cd6ad2c4-62d9-41dc-ade5-da7623fb3ea3" />


在 PyTorch 实现中，有三个容易踩坑的细节：

1. **输入与目标错位（Shift）及 Loss Masking**
* 模型在位置 $t$ 看到 $y_{\le t}$ 后预测 $y_{t+1}$。在 `transformers` 的 `CausalLM` 中，若传入 `labels`，模型内部会自动完成错位（Shift Logits 与 Shift Labels）并计算交叉熵损失（`CrossEntropyLoss`）。
* 做指令/对话微调时，通常把 **Prompt（用户输入）部分的 `labels` 设为 `-100`（`CrossEntropyLoss` 默认忽略 `-100`），只对**目标回复**计算梯度，避免模型把精力浪费在拟合问题本身。


2. **词表大小与分词器对齐**
* 如果向词表中新增了特殊 Token（如角色分隔符、工具调用标记），必须调用 `model.resize_token_embeddings(len(tokenizer))` 扩展 Embedding 与 LM Head 权重矩阵，否则 Token ID 越界会触发索引错误。


3. **混合精度与训练稳定性**
* 推荐使用 `torch.amp.autocast`（如 `bfloat16` 或 `float16`）配合梯度裁剪（`torch.nn.utils.clip_grad_norm_`），防止深层 Transformer 反向传播时出现梯度爆炸或溢出。

---

### 三、 训练与推理模式切换及常见坑点

1. **严格区分 `model.train()` 与 `model.eval()**`
* 训练时需处于 `model.train()` 以启用 Dropout 等正则化；推理时必须切回 `model.eval()` 并配合 `torch.inference_mode()` 或 `torch.no_grad()`，否则 Dropout 仍会随机丢弃神经元并保留无用状态。


2. **批处理推理时的 Padding 方向**
* 自回归生成（Causal LM）做 `batch_size > 1` 的并行生成时，应设置 `tokenizer.padding_side = "left"`，确保各序列末尾有效 Token 对齐，随后直接按 `gen_ids[:, gen_inputs["input_ids"].shape[-1]:]` 切片提取新生成内容不会因右侧 Pad 长度不同而错位。


3. **保存与复用权重**
* 使用 `transformers` 时，可通过 `model.save_pretrained(save_dir)` 与 `tokenizer.save_pretrained(save_dir)` 保存完整配置与权重，后续直接用 `from_pretrained(save_dir)` 恢复；纯 PyTorch 模块则建议保存 `torch.save(model.state_dict(), "model.pt")` 并在加载时显式实例化相同结构的模型类。
