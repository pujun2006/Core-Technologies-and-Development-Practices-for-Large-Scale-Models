Dynamic Graph Computation and Automatic Differentiation.py代码是一个经典的极简示例，完美展示了 PyTorch 的 **Autograd（自动微分引擎）** 是如何工作的。它通过一个包含两个变量的简单非线性函数，演示了**前向计算**与**反向传播求导**的全过程。

以下是逐行详细拆解与数学原理说明：

---

### 1. 创建带梯度追踪的输入张量

```python
x = torch.tensor([2.0, 3.0], requires_grad=True)

```

* **`torch.tensor([2.0, 3.0])`**：创建了一个包含两个元素的张量 $x$，其中 $x_0 = 2.0$，x1 = 3.0。
* **`requires_grad=True`**：这是一个极其关键的标志。它告诉 PyTorch：“这个张量是模型的参数（或需要求导的输入），请在后台默默帮我**追踪**对它进行的所有数学运算，以便后续自动求导。”

---

### 2. 定义计算图与前向传播

```python
y = x[0]**2 + x[1]**3

```

* **数学表达**：这里定义了一个标量函数 $y = x_0^2 + x_1^3$。
* **计算图构建（Forward Pass）**：
* 当执行这段代码时，PyTorch 的动态图机制开始生效。它不仅计算出了 $y$ 的数值，还在后台构建了一个有向无环图（DAG），记录了 $y$ 是如何由 $x_0$ 和 $x_1$ 经过平方、立方和加法运算得来的。


* **代入数值计算**：
* $x_0 = 2.0 \implies x_0^2 = 4.0$
* $x_1 = 3.0 \implies x_1^3 = 27.0$
* $y = 4.0 + 27.0 = 31.0$



---

### 3. 提取标量值

```python
print("y的值:", y.item())

```

* **`.item()`**：用于将一个只包含单个元素的 PyTorch 张量转换成标准的 Python 标量（float）。在这里，`y` 是一个 0 维张量（Scalar Tensor），使用 `.item()` 可以干净地打印出其数值 `31.0`，避免输出张量本身的附加信息（如数据类型、设备等）。

---

### 4. 触发反向传播（自动微分）

```python
y.backward()

```

* **核心求导操作**：调用 `.backward()` 后，PyTorch 的 Autograd 引擎会沿着刚才记录的计算图进行**反向遍历（Reverse-mode Autodiff）**，自动应用微积分的**链式法则（Chain Rule）**，计算出终点 $y$ 对起点 $x$ 中每个元素的偏导数（即梯度）。

#### 数学推导过程：

我们要求的偏导数是 $\frac{\partial y}{\partial x_0}$ 和 $\frac{\partial y}{\partial x_1}$：

1. 对 $x_0$ 求偏导：

$$\frac{\partial y}{\partial x_0} = \frac{\partial (x_0^2 + x_1^3)}{\partial x_0} = 2x_0$$



代入 x0 = 2.0：2 * 2.0 = 4.0

2. 对 $x_1$ 求偏导：

$$\frac{\partial y}{\partial x_1} = \frac{\partial (x_0^2 + x_1^3)}{\partial x_1} = 3x_1^2$$



代入 $x_1 = 3.0$：3 * (3.0)^2 = 3 * 9.0 = 27.0

---

### 5. 输出与查看梯度

```python
print("x的梯度:", x.grad)

```

* **`.grad` 属性**：在执行完 `y.backward()` 之后，计算出来的偏导数结果会被自动存入张量 $x$ 的 `.grad` 属性中。
* **输出结果**：运行该行代码，会打印出 `tensor([ 4., 27.], grad_fn=<CopyBackwards>)`。这正好对应了我们刚才数学推导出的导数结果 $[4.0, 27.0]$。
