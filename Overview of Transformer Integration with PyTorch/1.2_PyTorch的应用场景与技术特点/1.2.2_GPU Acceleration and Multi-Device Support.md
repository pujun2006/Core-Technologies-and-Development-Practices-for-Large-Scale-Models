GPU Acceleration and Multi-Device Support.py代码展示了在 PyTorch 中构建神经网络、处理多 GPU 并行计算（`DataParallel`）、定义优化器以及执行单步训练的标准流程。

下面进行详细的逐段拆解：

---

### 1. 设备检查与选择

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

```

* **作用**：检查当前环境是否支持 CUDA（即是否有 NVIDIA GPU）。如果可用，则将 `device` 设置为 `"cuda"`，否则退回 `"cpu"`。这使得代码具备良好的跨平台兼容性，能够在不同硬件环境中无缝运行。

---

### 2. 定义神经网络架构 (`SimpleNet`)

```python
class SimpleNet(nn.Module):

  def __init__(self):
    super(SimpleNet, self).__init__()
    self.fc1 = nn.Linear(100, 50)
    self.fc2 = nn.Linear(50, 10)
    self.fc3 = nn.Linear(10, 1)

  def forward(self, x):
    x = torch.relu(self.fc1(x))
    x = torch.relu(self.fc2(x))
    x = self.fc3(x)
    return x

```

* **`nn.Module`**：PyTorch 中所有神经网络模块的基类，自定义网络必须继承它。
* **`__init__`（构造函数）**：定义了网络包含的层。这里是一个简单的全连接前馈神经网络（MLP），包含三个线性层（`nn.Linear`）：
* 第一层：输入维度 100，输出维度 50。
* 第二层：输入维度 50，输出维度 10。
* 第三层：输入维度 10，输出维度 1（通常用于回归任务）。


* **`forward`（前向传播）**：定义了数据通过网络时的流动路径。在前两层之后应用了 ReLU 激活函数（`torch.relu`）以引入非线性特征，最后一层直接输出。

---

### 3 & 4. 实例化模型与多 GPU 并行封装

```python
model = SimpleNet().to(device)

if torch.cuda.device_count() > 1:
  print(f"使用多GPU进行计算，GPU数量: {torch.cuda.device_count()}")
  model = nn.DataParallel(model)

```

* **`.to(device)`**：将模型实例化并整体加载到指定的硬件设备（GPU 或 CPU）上。
* **`nn.DataParallel(model)`**：
* **关键点**：当机器检测到多于 1 张 GPU 时，使用 `DataParallel` 对模型进行包装。
* **工作原理**：在每次前向传播时，它会自动把输入的数据切分（Split）并并行分发到多张 GPU 上运行，最后将输出结果聚合（Gather）。



---

### 5. 定义优化器与损失函数

```python
optimizer = optim.SGD(model.parameters(), lr=0.01)
criterion = nn.MSELoss()

```

* **优化器 (`optimizer`)**：使用随机梯度下降（SGD），学习率设为 `0.01`。
* **注意顺序**：代码将优化器的定义放在了 `DataParallel` 封装之后。这是为了确保 `model.parameters()` 能够正确获取当前模型（如果是多 GPU，底层会变成 `model.module` 的参数）的所有可训练权重。


* **损失函数 (`criterion`)**：使用均方误差损失（`nn.MSELoss`），常用于衡量回归任务中预测值与真实值之间的差距。

---

### 6. 准备模拟数据

```python
input_data = torch.rand((64, 100), device=device)
target = torch.rand((64, 1), device=device)

```

* 使用 `torch.rand` 生成随机张量来模拟输入数据和标签。
* 批次大小（Batch Size）为 64，输入特征维度为 100，目标输出维度为 1。
* `.to(device)` 确保数据和模型在同一个计算设备上（都在 GPU 或都在 CPU）。

---

### 7. 训练步函数 (`train_step`)

```python
def train_step(model, data, target, criterion, optimizer):
  model.train()
  optimizer.zero_grad()
  output = model(data)
  loss = criterion(output, target)
  loss.backward()
  optimizer.step()
  return loss.item()

```

这是 PyTorch 中标准的**单步反向传播训练流程**，包含 6 个核心步骤：

1. **`model.train()`**：将模型设置为训练模式（对于包含 Dropout 或 BatchNorm 的网络尤为重要）。
2. **`optimizer.zero_grad()`**：清空优化器中累积的旧梯度，防止梯度叠加影响本轮更新。
3. **`output = model(data)`**：前向传播，计算模型的预测输出。
4. **`loss = criterion(output, target)`**：计算预测值与真实标签之间的损失值。
5. **`loss.backward()`**：反向传播，自动计算网络中各参数关于损失的梯度。
6. **`optimizer.step()`**：根据计算出的梯度，利用优化器（SGD）更新模型的权重参数。
7. **`loss.item()`**：将计算图中的 Tensor 损失值转换为 Python 的标准浮点数，方便打印和记录。

---

### 8. 运行训练并输出

```python
loss_val = train_step(model, input_data, target, criterion, optimizer)
print("训练损失:", loss_val)

```

* 调用刚刚定义好的 `train_step` 函数，执行一次完整的训练迭代，并打印出当前的损失值。
