Multi-layer stacking and residual connection.py代码完整实现了一个标准的 **Transformer 编码器层（Transformer Encoder Layer）**。它基于 PyTorch 的内置模块（如 `nn.MultiheadAttention`、`nn.LayerNorm` 等），遵循了经典的 Vaswani 等人提出的 Transformer 架构设计。

下面从**整体结构**、**初始化函数 (`__init__`)**、**前向传播逻辑 (`forward`)** 以及**测试输入输出**四个维度详细拆解这段代码：

---

### 一、 整体结构概述

一个标准的 Transformer 编码器层主要由两大核心子模块组成，每个子模块都伴随着**残差连接（Residual Connection）**和**层归一化（Layer Normalization）**：

1. **多头自注意力模块（Multi-Head Self-Attention）**：负责捕捉序列中不同词之间的全局上下文依赖。
2. **前馈神经网络模块（Position-wise Feed-Forward Network, FFN）**：负责对每个词的特征进行非线性变换。

---

### 二、 初始化函数 `__init__` 解析

```python
def __init__(self, d_model, num_heads, dim_feedforward, dropout=0.1):
    super(TransformerEncoderLayer, self).__init__()

```

* **参数含义**：
* `d_model = 4`：词嵌入维度（每个词的向量长度）。
* `num_heads = 2`：多头注意力的头数（必须能被 `d_model` 整除，即 $4 / 2 = 2$，每个头的维度为 $4 / 2 = 2$）。
* `dim_feedforward = 8`：前馈神经网络内部隐藏层的维度（通常设为 `d_model` 的 4 倍左右）。
* `dropout = 0.1`：随机丢弃率，用于防止过拟合。


* **各组件定义**：
1. **`nn.MultiheadAttention`**：PyTorch 官方提供的高效多头注意力实现。设置 `batch_first=True` 使得输入张量的维度顺序为 `(Batch, Seq_Len, Embedding_Dim)`，非常符合现代深度学习的习惯。
2. **前馈网络 (`linear1`, `linear2`)**：包含两个线性层和一个 ReLU 激活函数。先将维度从 `d_model`（4）放大到 `dim_feedforward`（8），再缩减回 `d_model`（4）。
3. **残差与归一化 (`norm1`, `norm2`, `dropout1`, `dropout2`)**：
* 代码采用的是经典的 **Post-LN（Post-Layer Normalization）** 架构，即在残差加和之后再进行层归一化：<img width="340" height="40" alt="590d14c0-c7bf-4108-9e83-228b1cfa63d8" src="https://github.com/user-attachments/assets/551c6c96-7561-4598-b794-bc4fa27b4abc" />
。
* 使用 `nn.LayerNorm(d_model)` 对每个词的特征维度进行归一化。

### 三、 前向传播函数 `forward` 解析

当输入张量 `src` 进入编码器层时，会依次经历两个主要步骤：

#### 步骤 1：多头自注意力子层

```python
attn_output, _ = self.multihead_attn(src, src, src)
src = self.norm1(src + self.dropout1(attn_output))

```

* **自注意力计算**：`self.multihead_attn(src, src, src)` 中的三个参数分别代表 Query、Key 和 Value。在自注意力中，这三者都是输入矩阵 `src` 本身。
* **残差连接与归一化**：将注意力计算的输出 `attn_output` 经过 Dropout 后，与原始输入 `src` 相加（残差连接），最后送入 `LayerNorm`（`norm1`）。这有效缓解了深层网络中的梯度消失问题。

#### 步骤 2：前馈神经网络子层

```python
ff_output = self.linear2(self.dropout(F.relu(self.linear1(src))))
src = self.norm2(src + self.dropout2(ff_output))

```

* **非线性变换**：经过注意力层整合了全局上下文的 `src`，逐个位置地通过全连接前馈网络进行特征提取（`linear1` $\rightarrow$ `ReLU` $\rightarrow$ `Dropout` $\rightarrow$ `linear2`）。
* **残差连接与归一化**：同样地，将前馈网络的输出与进入该子层前的输入进行残差相加，再通过第二个 `LayerNorm`（`norm2`），最终返回编码器层的输出 `src`。
