Comprehensive guide to custom model configuration and parameter adjustment.py代码展示了一个完整的 **PyTorch 原生微调闭环**：从加载带自定义正则化（Dropout）的预训练分类模型、准备张量输入、执行训练循环与权重更新，到持久化保存模型与分词器，最后重新加载进行推理。

下面按执行步骤拆解核心逻辑与工程要点：

---

### 1. 加载 Tokenizer 与带自定义 Dropout 的模型（第 1 步）

```python
model = AutoModelForSequenceClassification.from_pretrained(
    model_name,
    num_labels=2,
    hidden_dropout_prob=0.3,
    attention_probs_dropout_prob=0.3,
)

```

* **修改正则化超参数**：BERT 默认的 Dropout 概率通常为 `0.1`；在小样本或易过拟合任务中，在 `from_pretrained()` 时直接传入 `hidden_dropout_prob` 与 `attention_probs_dropout_prob`，会覆盖配置并立即生效于新建的模型层。
* **分类头初始化**：`num_labels=2` 会在编码器输出上接一个二分类线性层，初始参数随机初始化，需要在微调中学习。

---

### 2. 数据编码与标签拼接（第 2 步）

```python
inputs = tokenizer(
    sentences, padding=True, truncation=True, return_tensors="pt"
)
inputs["labels"] = torch.tensor(labels)

```

* `padding=True` 会按当前批次中最长序列补齐（此处只有 2 句话），`return_tensors="pt"` 直接返回 PyTorch 张量（包含 `input_ids`、`attention_mask` 等）。
* **关键约定**：在 Hugging Face 分类模型中，传入 `labels` 张量（形状 `[batch_size]`，整型类别索引）后，模型前向传播时会自动计算交叉熵损失（`CrossEntropyLoss`），无需手写损失函数。

---

### 3. 定义 PyTorch 原生优化器（第 3 步）

```python
optimizer = AdamW(model.parameters(), lr=2e-5, weight_decay=0.01)

```

* 使用 `torch.optim.AdamW` 对 Transformer 微调非常常见，`2e-5` 是 BERT 类模型常用的较小学习率，避免破坏预训练语义表征；`weight_decay=0.01` 提供 L2 权重衰减正则化。
* 工程上常见做法是对 `bias` 和 `LayerNorm` 参数排除 `weight_decay`，不过在小型示例或快速实验中直接传入 `model.parameters()` 也很直观。

---

### 4. 训练循环与梯度更新（第 4 步）

```python
model.train()
for epoch in range(3):
    optimizer.zero_grad()
    outputs = model(**inputs)
    loss = outputs.loss
    logits = outputs.logits
    loss.backward()
    optimizer.step()

```

* **`model.train()`**：开启训练模式，使 Dropout 随机丢弃神经元生效，并让层处于训练状态。
* **标准 5 步训练骨架**：
1. `optimizer.zero_grad()`：清空上一轮累积的梯度；
2. `outputs = model(**inputs)`：前向计算并返回 `SequenceClassifierOutput`（含 `loss` 与 `logits`）；
3. `loss.backward()`：反向传播计算各参数梯度；
4. `optimizer.step()`：根据梯度与学习率更新模型权重。


* **注意**：这里为了演示闭环，直接用 2 条样本跑了 3 个 epoch（属于过拟合演示/流程验证，真实训练通常会有划分出的训练集与验证集、分批 `DataLoader` 以及学习率调度器）。

---

### 5. 模型与 Tokenizer 持久化保存（第 5 步）

```python
model.save_pretrained("./finetuned_bert")
tokenizer.save_pretrained("./finetuned_bert")

```

* `save_pretrained()` 会将模型权重（如 `model.safetensors` 或 `pytorch_model.bin`）、修改后的 `config.json`（含 `0.3` 的 Dropout 配置与 `num_labels=2`）以及分词器文件一起写入 `./finetuned_bert`。
* **两者成对保存很重要**：确保后续推理时使用的词表与模型结构、权重完全匹配。

---

### 6. 重新加载与推理预测（第 6 步）

```python
finetuned_model.eval()
...
with torch.no_grad():
    outputs = finetuned_model(**test_inputs)
    probabilities = torch.softmax(outputs.logits, dim=-1)
    predicted_label = torch.argmax(probabilities, dim=1).item()

```

* **`finetuned_model.eval()`**：切换到评估模式，**关闭 Dropout**，保证推理结果确定且分布稳定。
* **`torch.no_grad()`**：禁用梯度计算图构建，显著降低显存/内存占用并加快推理速度。
* **`torch.softmax(..., dim=-1)` 与 `torch.argmax(..., dim=1)**`：将原始未归一化输出 `logits` 转换为各类别概率分布，并取出最高概率对应的类别索引（`0` 或 `1`）。

### 工程小贴士

* **类别名称可读性**：如果希望预测结果直接输出 `"正面"` / `"负面"` 而非 `0` / `1`，可以在加载模型时传入 `id2label` 和 `label2id`，之后通过 `finetuned_model.config.id2label[predicted_label]` 即可转换。
* **真实数据集接入**：数据量变大后，建议用 `datasets.Dataset` + `torch.utils.data.DataLoader` 做分批迭代与打乱，而不是把整批数据一次性塞进单步前向传播。
