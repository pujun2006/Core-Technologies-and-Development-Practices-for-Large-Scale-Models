Custom Training Loops and Evaluation Metrics.py代码展示了一个基于 `datasets.Dataset`、`torch.utils.data.DataLoader`、`transformers` 与 `scikit-learn` 的**分批训练与准确率评估**实现。相比之前把整批数据直接硬编码进循环的写法，它引入了 `DataLoader` 批处理、张量格式化（`set_format`）以及独立的 `train_model` / `evaluate_model` 函数。

下面按代码流程拆解核心逻辑与工程细节：

---

### 1. 加载模型、分词器与构建数据集（第 1～2 步）

```python
model_name = "bert-base-uncased"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name, num_labels=2)

data = {
    "text": [...],
    "label": [1, 1, 0],
}
dataset = Dataset.from_dict(data)

```

* 加载 `bert-base-uncased` 的分词器与二分类模型（`num_labels=2`），并将原始字典转换为 Hugging Face `Dataset` 对象。

---

### 2. 数据预处理与 PyTorch 张量格式化（第 3 步）

```python
def preprocess_data(examples):
    tokenized_inputs = tokenizer(
        examples["text"], padding="max_length", truncation=True, max_length=32
    )
    tokenized_inputs["labels"] = examples["label"]
    return tokenized_inputs

dataset = dataset.map(preprocess_data, batched=True)
dataset.set_format(type="torch", columns=["input_ids", "attention_mask", "labels"])

```

* **`preprocess_data`**：批量对 `"text"` 分词、补齐/截断至 `max_length=32`，并将 `"label"` 写入 `"labels"`（模型计算损失默认读取的字段名）。
* **`dataset.set_format(type="torch", columns=[...])`**：这是本段代码的一个亮点——在 `map` 阶段保持纯 Python 列表/字典，随后通过 `set_format(type="torch", ...)` 指定输出张量格式与保留列，既干净又避免提前在 `map` 内部手动拼装 Tensor。

---

### 3. 使用 `DataLoader` 构建批次（第 4 步）

```python
train_dataloader = DataLoader(dataset, batch_size=2, shuffle=True)
eval_dataloader = DataLoader(dataset, batch_size=2, shuffle=False)

```

* **`batch_size=2`**：3 条样本会被拆分为 2 个批次（第 1 批 2 条，第 2 批 1 条）。
* **`shuffle=True` vs `shuffle=False**`：训练集开启打乱顺序，有助于提升训练泛化；评估集关闭打乱，保证遍历顺序稳定可复现。

---

### 4. 设备与优化器配置（第 5 步）

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model = model.to(device)
optimizer = AdamW(model.parameters(), lr=2e-5)

```

* 自动检测是否有可用 GPU（`cuda`），否则使用 `cpu`，并将模型迁移至目标设备，再使用 `AdamW`（学习率 `2e-5`）管理模型参数。

---

### 5. 自定义训练循环（第 6 步）

```python
def train_model(model, dataloader, optimizer, epochs=3):
    model.train()
    for epoch in range(epochs):
        total_loss = 0
        for i, batch in enumerate(dataloader):
            batch = {k: v.to(device) for k, v in batch.items()}
            outputs = model(**batch)
            loss = outputs.loss
            total_loss += loss.item()

            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            ...
        avg_loss = total_loss / len(dataloader)

```

* **训练模式与设备迁移**：`model.train()` 开启训练态；每个 batch 字典中的张量都通过字典推导式统一搬运到 `device`。
* **自动算损与反向更新**：`model(**batch)` 传入 `labels` 后自动返回 `outputs.loss`；随后依次执行 `optimizer.zero_grad()`、`loss.backward()`、`optimizer.step()`。
* **批次与轮次统计**：打印每个 batch 的损失及每个 epoch 的平均损失（`total_loss / len(dataloader)`）。

---

### 6. 自定义评估函数与执行（第 7～8 步）

```python
def evaluate_model(model, dataloader):
    model.eval()
    predictions, true_labels = [], []
    with torch.no_grad():
        for batch in dataloader:
            batch = {k: v.to(device) for k, v in batch.items()}
            outputs = model(**batch)
            logits = outputs.logits
            preds = torch.argmax(logits, dim=-1)
            predictions.extend(preds.cpu().numpy())
            true_labels.extend(batch["labels"].cpu().numpy())
    accuracy = accuracy_score(true_labels, predictions)

```

* **评估模式与无梯度推理**：`model.eval()` 关闭 Dropout 等训练层行为，`with torch.no_grad():` 禁用梯度计算以节省显存/内存。
* **全量收集后计算准确率**：将各批次预测类别（`torch.argmax(logits, dim=-1)`）与真实标签移回 CPU 转成 NumPy 后拼接，最后用 `accuracy_score(true_labels, predictions)` 计算整体准确率。

### 8. 工程实践中的可改进点

1. **划分独立验证/测试集**：当前示例为了精简，直接把同一份 `dataset` 同时传给了 `train_dataloader` 和 `eval_dataloader`。实际项目中建议先用 `dataset.train_test_split(...)` 拆出独立的训练集与验证集，防止评估结果虚高。
2. **补充更多评估指标与最优权重保存**：除 `accuracy_score` 外，实际业务中常结合 F1、精确率/召回率或验证损失，并在验证集表现提升时保存最佳模型权重。
3. **动态 Padding**：当前统一补齐到 `max_length=32`；若数据集序列长短不一，改用 `DataCollatorWithPadding(tokenizer=tokenizer)` 按批次最长样本动态补齐，通常能减少不必要的填充计算。
