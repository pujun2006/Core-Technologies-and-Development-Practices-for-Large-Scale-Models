Design of Distilled Models and Training Techniques for Small Models.py代码实现了一个完整的**文本分类任务知识蒸馏（Knowledge Distillation）训练管线**，采用经典的 **Hinton 软标签 + 硬标签联合损失**，让小模型 `prajjwal1/bert-tiny` 学习大模型 `bert-base-uncased` 的输出分布，并引入了**随训练轮次线性退火的动态 `alpha` 调度策略**。

下面按核心模块拆解其数学原理、代码实现与工程细节：

---

### 一、 联合蒸馏损失函数：`DistillationLoss`（第 1 部分）

```python
class DistillationLoss(nn.Module):

    def __init__(self, temperature=2.0, alpha=0.5):
        super(DistillationLoss, self).__init__()
        self.temperature = temperature
        self.alpha = alpha
        self.ce_loss = nn.CrossEntropyLoss()
        self.kl_div = nn.KLDivLoss(reduction="batchmean")

    def forward(self, student_logits, teacher_logits, labels):
        soft_student = torch.log_softmax(student_logits / self.temperature, dim=-1)
        soft_teacher = torch.softmax(teacher_logits / self.temperature, dim=-1)
        distillation_loss = self.kl_div(soft_student, soft_teacher) * (
            self.temperature**2
        )

        ce_loss = self.ce_loss(student_logits, labels)

        return self.alpha * distillation_loss + (1.0 - self.alpha) * ce_loss

```

#### 1. Soft Target 损失（KL 散度 + 温度缩放）

* **温度平滑**：将 `student_logits` 与 `teacher_logits` 同时除以 `temperature`（默认 `2.0`），再分别计算 `log_softmax` 与 `softmax`。温度大于 `1` 时会平滑概率分布，暴露非最大类别之间的相对概率结构（即“暗知识”）。
* **`reduction="batchmean"` 与 `temperature ** 2` 缩放**：
* `nn.KLDivLoss(reduction="batchmean")` 按批次均值计算 KL 散度（PyTorch 官方建议在分布对齐时使用 `"batchmean"` 以符合数学定义）。
* 当 Logits 除以 $T$ 后，对 Logits 求导的梯度幅值会缩小约 $1/T^2$ 倍；乘以 $T^2$ 可以使软标签损失的梯度量级与硬标签交叉熵损失保持在同一尺度，避免蒸馏梯度随温度升高而过度衰减。



#### 2. Hard Target 损失与加权融合

* `ce_loss` 直接将未缩放的 `student_logits` 与真实标签 `labels` 做交叉熵，锚定真实分类目标。
* 最终损失为 `alpha * distillation_loss + (1 - alpha) * ce_loss`，在“模仿教师分布”与“对齐真实标签”之间做加权平衡。

### 二、 单轮训练循环：`train_student_model`（第 2 部分）

```python
student_model.train()
teacher_model.eval()

```

* **模式区分**：`student_model` 设为 `.train()` 以启用 Dropout 等训练层并更新参数；`teacher_model` 设为 `.eval()` 关闭 Dropout 等随机正则层，确保教师输出稳定。
* **推理隔离与设备对齐**：
* 教师模型前向包裹在 `with torch.no_grad():` 中，不构建计算图、不累计梯度，降低显存峰值并加快推理。
* 每个 Batch 的 `input_ids`、`attention_mask`、`labels` 均显式移动到目标 `device`，保证张量设备一致。


* **标准优化步骤**：`optimizer.zero_grad()` -> `loss.backward()` -> `optimizer.step()`，仅对 `student_model` 参数更新。

### 三、 动态权重调度：`dynamic_alpha_schedule`（第 3 部分）

```python
def dynamic_alpha_schedule(epoch, total_epochs, start_alpha=0.7, end_alpha=0.3):
    return start_alpha + (end_alpha - start_alpha) * (epoch / total_epochs)

```

* **线性退火逻辑**：在主循环中，每个 Epoch 开始时按 `epoch / total_epochs` 计算当前 `alpha` 并更新 `distillation_loss_fn.alpha`。
* `epoch = 0` 时，`alpha = 0.7`（前阶段更侧重向教师模型学习平滑分布与类间关系）；
* 随着 `epoch` 推进，`alpha` 逐步向 `0.3` 靠近（后阶段加大 `1 - alpha` 的权重，更侧重向真实 `labels` 收敛，减少教师模型自身偏差的残留）。


* **注意边界情况**：当 `total_epochs > 1` 且 `epoch` 从 `0` 到 `total_epochs - 1` 时，最后一个 Epoch 的 `epoch / total_epochs` 约为 `(total_epochs - 1) / total_epochs`（本例中 `4 / 5 = 0.8`，对应 `alpha = 0.38`）。若希望最后一个 Epoch 精确达到 `end_alpha`，可将分母改为 `max(total_epochs - 1, 1)`。

### 四、 主程序结构与工程使用提示（第 4 部分）

1. **教师模型冻结**：
```python
for param in teacher_model.parameters():
    param.requires_grad = False

```


显式关闭教师参数梯度，既防止误更新教师权重，也进一步减少反向传播时的梯度相关开销。
2. **示例数据集与任务适配**：
* `create_dummy_dataset` 构造了 16 条占位样本与二分类标签，用于快速验证代码可跑通与损失变化；实际训练时需替换为真实文本分类数据集，并注意**教师模型最好先在目标任务上微调至较高水平**（若直接用未经任务微调的 `bert-base-uncased` 分类头做教师，其随机初始化分类头的 Logits 指导意义有限）。


3. **跨架构维度与标签映射**：
* 本例中 `bert-base-uncased` 与 `prajjwal1/bert-tiny` 均采用 `BertForSequenceClassification` 且 `num_labels=2`，因此 `student_logits` 与 `teacher_logits` 维度天然一致（均为 `[batch_size, 2]`），可直接做 Logits/KL 蒸馏；若涉及隐藏层特征蒸馏（Hidden States），则需额外添加线性投影层对齐两者的 `hidden_size`（如 `768` 与 `128`）。
