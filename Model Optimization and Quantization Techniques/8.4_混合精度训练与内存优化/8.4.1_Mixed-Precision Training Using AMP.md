Mixed-Precision Training Using AMP.py代码使用 PyTorch 新一代统一接口（`torch.amp.autocast` 与 `torch.amp.GradScaler`）对一个无池化层的卷积神经网络（`SimpleCNN`）演示了**自动混合精度（AMP）训练**与**混合精度推理**的完整流程，并兼顾了无 GPU（CPU）环境下的平滑回退。

下面按模块逐一拆解其原理与工程细节。

---

### 一、 网络结构与维度计算

```python
class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, stride=1, padding=1)
        self.bn1 = nn.BatchNorm2d(16)
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, stride=1, padding=1)
        self.bn2 = nn.BatchNorm2d(32)

        # 28x28 图像无池化时尺寸保持 28x28，维度为 32 * 28 * 28 = 25088
        self.fc1 = nn.Linear(32 * 28 * 28, 128)
        self.fc2 = nn.Linear(128, 10)

```

* **特征图尺寸保持不变**：两次 `3x3` 卷积均使用 `stride=1, padding=1`，因此输入 `(16, 1, 28, 28)` 经过卷积、BatchNorm 与 `torch.relu` 后，空间分辨率仍为 `28x28`，通道数变为 `32`。
* **展平与全连接对齐**：`torch.flatten(x, 1)` 将每个样本的特征展平为 `32 * 28 * 28 = 25088` 维，与 `fc1` 的输入维度精确匹配，最后输出 10 个类别的 Logits。

### 二、 设备检测与 `GradScaler` 初始化

```python
device = "cuda" if torch.cuda.is_available() else "cpu"
...
scaler = torch.amp.GradScaler("cuda", enabled=(device == "cuda"))

```

* **`torch.amp.GradScaler("cuda", enabled=...)`**：这是 PyTorch 推荐的统一 `torch.amp` 写法，显式指明 `"cuda"` 后端。
* **`enabled=(device == "cuda")` 的意义**：当运行在 CUDA 设备上时，`GradScaler` 会对 `FP16` 梯度做动态缩放与溢出检测；若当前环境只有 CPU（`device == "cpu"`），`enabled=False` 会让 `scaler` 变为安全的空操作（pass-through），无需修改代码即可在 CPU 上跑通整套流程。
* **补充提示**：在支持 `BF16` 且选择使用 `BF16` 训练时，通常不需要依赖 `GradScaler`（或按需配置 `dtype=torch.bfloat16`）；默认未指定 `dtype` 时，CUDA 上的 `autocast` 通常以 `float16` 为主。

### 三、 AMP 训练循环 `train_amp`

```python
def train_amp(model, optimizer, criterion, scaler, num_epochs=5):
    model.train()
    for epoch in range(num_epochs):
        optimizer.zero_grad()

        with torch.amp.autocast(device_type="cuda", enabled=(device == "cuda")):
            outputs = model(input_data)
            loss = criterion(outputs, labels)

        scaler.scale(loss).backward()
        scaler.step(optimizer)
        scaler.update()

        print(f"Epoch [{epoch+1}/{num_epochs}], Loss: {loss.item():.4f}")

```

1. **切换训练模式与清零梯度**：`model.train()` 启用 Dropout/BatchNorm 训练行为；每步开始调用 `optimizer.zero_grad()` 清空上一轮梯度。
2. **`autocast` 包裹前向与 Loss 计算**：
* 在 `with torch.amp.autocast(device_type="cuda", enabled=(device == "cuda")):` 块内，`Conv2d`、`Linear` 等计算密集算子会自动以低精度执行以提升吞吐并节省中间激活显存，而 `CrossEntropyLoss` 等数值敏感操作则会按规则以高精度计算，兼顾速度与稳定性。


3. **梯度缩放与更新三部曲**：
* **`scaler.scale(loss).backward()`**：将放大的 Loss 反向传播，放大梯度以减少 `FP16` 下的梯度下溢。
* **`scaler.step(optimizer)`**：先将梯度反缩放回正常尺度；若检测到梯度中存在 `Inf` 或 `NaN`，则跳过本步 `optimizer.step()`，避免破坏权重。
* **`scaler.update()`**：根据本步是否发生梯度溢出，动态调整下一次迭代的缩放因子 `scale`。

### 四、 AMP 推理测试 `test_inference_amp`

```python
def test_inference_amp(model, input_data):
    model.eval()
    with torch.no_grad():
        with torch.amp.autocast(
            device_type="cuda", enabled=(device == "cuda")
        ):
            output = model(input_data)
            print("推理输出示例 (前 10 维):\n", output[0, :10])

```

* **`model.eval()` + `torch.no_grad()**`：推理阶段关闭梯度计算与训练态统计更新，减少显存占用与调度开销。
* **推理阶段使用 `autocast`（无需 `GradScaler`）**：推理没有反向传播与梯度下溢问题，因此不需要 `GradScaler`；在 `autocast` 上下文中跑前向推理，可利用低精度矩阵乘提升吞吐并降低激活显存占用。

### 六、 工程实践注意事项

* **多卡或 CPU 场景的 `device_type**`：若在 CPU 上希望启用 CPU `bfloat16` `autocast`，需将 `device_type` 设为 `"cpu"`；在多卡分布式训练中，通常会将 `device_type` 设为 `"cuda"` 并确保张量位于对应 GPU 设备上。
* **当前为合成数据演示**：代码中用的是 `torch.rand` / `torch.randint` 造的假数据（且单步 batch 固定为 16），适合验证代码结构与 AMP 流程；实际训练时需接入真实 `DataLoader`、划分训练/验证集并评估收敛准确率与显存/吞吐收益。
