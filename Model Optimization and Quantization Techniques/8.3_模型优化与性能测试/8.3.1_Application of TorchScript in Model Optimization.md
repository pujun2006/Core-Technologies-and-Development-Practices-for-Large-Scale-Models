Application of TorchScript in Model Optimization.py代码演示了如何将一个带有卷积层、批归一化（BatchNorm）与池化层的 `SimpleCNN` 模型，分别通过 **`torch.jit.trace`** 和 **`torch.jit.script`** 转换为 TorchScript 模型，完成序列化保存（`.pt`）与重新加载，并在 CPU 上对比各阶段连续 100 次前向推理的耗时。

下面按模块逐一拆解其原理与工程细节。

---

### 一、 模型结构与维度匹配

```python
class SimpleCNN(nn.Module):
    def __init__(self):
        ...
        self.pool1 = nn.MaxPool2d(2, 2)  # 28x28 -> 14x14
        ...
        self.pool2 = nn.MaxPool2d(2, 2)  # 14x14 -> 7x7
        self.fc1 = nn.Linear(32 * 7 * 7, 128)

```

* **特征图尺寸演进**：对于 `(batch_size, 1, 28, 28)` 的输入，经过两次 `2x2` 最大池化（`stride=2`）后，空间尺寸从 `28x28` 缩小为 `14x14`，再变为 `7x7`；通道数由 `1` 变为 `16`，再变为 `32`。展平（`torch.flatten(x, 1)`）后的特征维度恰好为 `32 * 7 * 7 = 1568`，与 `fc1` 的输入维度精确匹配。
* **函数式调用 `torch.relu(...)**`：前向传播中直接调用 `torch.relu` 而非 `nn.ReLU()` 模块，在 `trace` 和 `script` 下都能正常记录/编译为算子；由于本网络没有 `if/for` 动态分支，两种导出方式都能完整捕获计算图。

### 二、 推理计时与预热机制

```python
def test_inference(model_obj, input_tensor, description=""):
    with torch.no_grad():
        for _ in range(10):
            _ = model_obj(input_tensor)

    start = time.time()
    with torch.no_grad():
        for _ in range(100):
            output = model_obj(input_tensor)
    end = time.time()

```

* **10 次预热（Warm-up）**：避免首次前向传播时的缓存冷启动、JIT 图初始化或线程池唤醒影响正式计时。
* **`torch.no_grad()` 与批量计时**：关闭梯度计算后，对 `(16, 1, 28, 28)` 的输入连续执行 100 次前向推理，统计总耗时并打印。

### 三、 TorchScript 转换、持久化与加载

#### 1. `eval()` 模式的重要性

```python
model = SimpleCNN().to("cpu")
model.eval()

```

* 转换前调用 `model.eval()` 可确保 `BatchNorm2d` 使用固定的运行均值与方差（而非 batch 统计量），并避免训练态逻辑混入推理图。

#### 2. 追踪法（Trace）与脚本法（Script）

```python
traced_model = torch.jit.trace(model, input_data)
scripted_model = torch.jit.script(model)

```

* **`torch.jit.trace`**：用 `input_data` 跑一遍前向，记录实际执行的算子序列生成 `ScriptModule`。适合这种结构固定、无动态分支的 CNN。
* **`torch.jit.script`**：直接解析 Python 源码与 AST 生成 TorchScript IR。虽然本模型没有分支逻辑，但 `script` 能保留源码级的控制流表达能力，后续若在 `forward` 中加入条件判断会更安全。

#### 3. 序列化与反序列化（`.save` / `.load`）

```python
traced_model.save("traced_model.pt")
scripted_model.save("scripted_model.pt")

loaded_traced_model = torch.jit.load("traced_model.pt")
loaded_scripted_model = torch.jit.load("scripted_model.pt")

```

* `.save()` 将计算图结构与权重参数打包写入磁盘文件；`torch.jit.load()` 可在独立环境或后续流程中直接恢复模型，无需重新执行原 Python 模型类定义或 `trace`/`script` 过程。
