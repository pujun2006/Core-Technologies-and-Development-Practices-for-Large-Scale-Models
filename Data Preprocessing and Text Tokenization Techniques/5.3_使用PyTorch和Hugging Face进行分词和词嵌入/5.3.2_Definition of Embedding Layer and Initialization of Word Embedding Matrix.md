Definition of Embedding Layer and Initialization of Word Embedding Matrix.py代码展示了如何从 Hugging Face 的预训练模型 `bert-base-chinese` 中**直接提取真实的预训练词嵌入层（Input Embeddings）**，并将中文文本编码后的 `input_ids` 映射为高维稠密向量。与随机初始化的 `nn.Embedding` 相比，这里查出来的向量已经承载了预训练阶段学到的词表级语义先验。

### 一、 分步详细解析

#### 1. 加载分词器与预训练模型（第 1 步）

* `model_name = "bert-base-chinese"`：指定中文 BERT 基座模型。
* `tokenizer = AutoTokenizer.from_pretrained(model_name)`：加载对应的分词器，确保切分规则与词表索引和模型权重严格一致。
* `model = AutoModel.from_pretrained(model_name)`：加载包含词嵌入层和 12 层 Transformer Encoder 的预训练模型权重。

#### 2. 提取真实预训练词嵌入层（第 2 步）

* `pretrained_embedding_layer = model.get_input_embeddings()`：获取模型输入端的词嵌入模块（在 BERT 中即 `word_embeddings`，底层对应形状为 `(vocab_size, 768)` 的可学习权重矩阵）。
* 通过 `model.get_input_embeddings()` 而不是手写 `nn.Embedding(vocab_size, 768)`，可以直接复用预训练好的向量权重，避免从零随机初始化。

#### 3. 文本分词与张量对齐（第 3 步）

* `texts = ["自然语言处理是一门研究计算机理解和生成人类语言的学科。"]`：传入 1 条中文句子（注意实际长度为 24 个字符左右，加上 `[CLS]` 和 `[SEP]` 会更长）。
* `tokenizer(..., padding="max_length", truncation=True, max_length=20, return_tensors="pt")`：
* 将文本切分并自动加上 `[CLS]`（开头）与 `[SEP]`（结尾）；
* `max_length=20` 配合 `truncation=True` 会把超出的尾部 token 截断，最终输出长度为 `20` 的序列；
* `return_tensors="pt"` 直接返回 PyTorch 张量，随后取出 `input_ids`（形状为 `(1, 20)`）。



#### 4. 查表获取词嵌入与结果打印（第 4～5 步）

* `with torch.no_grad():`：当前只是做前向查表与查看数值，关闭梯度计算可节省显存与计算开销。
* `embeddings = pretrained_embedding_layer(input_ids)`：
* 根据 `input_ids` 中的每个整数 ID 去嵌入权重矩阵中取对应行向量；
* 输入形状为 `(batch_size=1, seq_len=20)`，输出 `embeddings` 形状为 `(1, 20, 768)`（`bert-base` 的隐藏层维度 `hidden_size` 为 `768`）。


* 最后打印张量形状，并用 `embeddings[0, :5, :4]` 切片查看第 `0` 条样本、前 `5` 个 token、前 `4` 个特征维度的具体浮点数值。

### 二、 关键概念与潜在注意点

1. **这是“静态/词表级词嵌入”，不是“上下文隐藏状态”**：
* `pretrained_embedding_layer(input_ids)` 只完成了**词表查表**，尚未加上位置嵌入（Position Embeddings）和类型嵌入（Token Type Embeddings），也还没有经过 BERT 各层自注意力的上下文交互。
* 如果需要上下文相关的表示，应直接前向调用 `model(**tokenized_inputs)` 取 `outputs.last_hidden_state`；若需要仅包含词嵌入 + 位置嵌入 + 类型嵌入的输入层总表示，则需看 `model.bert.embeddings(...)` 的输出。


2. **`max_length=20` 会发生截断**：
* 这句中文句子原长超过 20 个 token，设置 `max_length=20` 且 `truncation=True` 时，句尾部分（如“的学科。”及 `[SEP]`）会被裁剪掉。若想保留整句，可适当调大 `max_length`（例如 `32` 或 `64`）。
