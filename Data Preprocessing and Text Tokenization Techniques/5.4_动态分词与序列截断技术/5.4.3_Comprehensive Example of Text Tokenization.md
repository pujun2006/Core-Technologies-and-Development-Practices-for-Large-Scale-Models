Comprehensive Example of Text Tokenization.py代码演示了一套**中文文本预处理与预训练词向量（Embedding）提取**的完整流程。它基于 Hugging Face `transformers` 中的 `bert-base-chinese` 模型，把原始中文句子依次经过**清洗、分词/填充、转换为 Embedding 张量**，最终得到可直接送入下游网络或用于分析的向量表示。

---

### 一、 总体处理流程

```text
原始中文文本 (texts)
   │
   ▼  1. 文本清洗 (clean_chinese_text)
去除标点、停用词、空白字符 (cleaned_texts)
   │
   ▼  2. 分词、截断与填充 (tokenize_and_pad)
转为 Token ID 序列 + 统一长度 max_length=20 (input_ids, attention_mask 等)
   │
   ▼  3. 预训练 Embedding 层映射 (get_input_embeddings)
查表映射为稠密向量 (embeddings: [batch_size, seq_len, hidden_size])

```

---

### 二、 分步骤详细解析

#### 1. 加载 Tokenizer 和 BERT 预训练模型

```python
model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
bert_model = AutoModel.from_pretrained(model_name)

```

* **`bert-base-chinese`**：面向中文的经典 BERT 基础模型（12 层 Transformer Encoder、隐藏层维度 `768`、词表大小约 `21128`），中文以字（Character）为基本建模单元。
* **`AutoTokenizer`**：负责将字符串切分为模型词表中的 Token，并映射为整数 ID（`input_ids`），同时生成 `attention_mask`（标记有效 token 与 padding 位置）和 `token_type_ids`。
* **`AutoModel`**：加载不含特定任务头（如分类头、问答头）的纯 BERT 编码器主干。

#### 2. 停用词与原始语料定义

```python
stopwords = {"的", "和", "在", "是", "了", "也", "有", "与", "对", "就"}
texts = [...]

```

* `stopwords` 使用 Python `set`（集合）存储高频虚词/功能词，集合的查找时间复杂度为 $O(1)$，比列表更快。
* `texts` 是一个包含 3 条中文句子的列表，且每句话长短不一，体现了真实批次（Batch）数据长度不对齐的常见情况。

#### 3. 中文文本清洗函数（按单字过滤）

```python
def clean_chinese_text(text, stopwords):
    text = re.sub(r"[^\w\s]", "", text)
    chars = list(text)
    filtered_chars = [
        char for char in chars if char not in stopwords and not char.isspace()
    ]
    return "".join(filtered_chars)

```

* **`re.sub(r"[^\w\s]", "", text)`**：`\w` 匹配字母、数字、下划线以及 Unicode 汉字字符；`\s` 匹配空白符。`[^\w\s]` 表示**除字母/数字/下划线/汉字/空白以外的字符**（即常见标点符号，如 `，`、`。`），替换为空字符串 `""` 即将其移除。
* **`chars = list(text)`**：将清洗后的字符串拆分为单字列表。注释中也提示：如果希望按“词”过滤停用词，应先用 `jieba` 等分词工具切词，再过滤词级停用词。
* **`char not in stopwords and not char.isspace()`**：过滤掉停用词集合中的单字以及空格、制表符、换行符等空白字符。
* **`"".join(filtered_chars)`**：重新拼回连续字符串，方便后续直接交给 `tokenizer` 处理。

#### 4. 分词、截断与填充（Tokenize & Pad）

```python
def tokenize_and_pad(texts, tokenizer, max_length=20):
    return tokenizer(
        texts,
        padding="max_length",
        truncation=True,
        max_length=max_length,
        return_tensors="pt",
    )

```

神经网络（尤其是批量矩阵运算）要求同一批次内的样本形状规整，因此需要统一序列长度：

* **`padding="max_length"`**：长度不足 `max_length`（这里是 `20`）的序列，会在右侧补 `[PAD]` token（在 `bert-base-chinese` 中对应 ID 通常为 `0`）。
* **`truncation=True`**：长度超过 `max_length` 的序列会被截断到最大长度（注意：BERT 编码时通常会占用 `[CLS]` 和 `[SEP]` 两个特殊符号位，实际可用正文长度会少 2 个）。
* **`return_tensors="pt"`**：直接返回 PyTorch 张量（`torch.Tensor`），省去手动转换。

输出 `tokenized_inputs` 是一个字典，包含：

* `input_ids`：形状为 `[3, 20]`（3 条文本，每条长度 20）。
* `token_type_ids`：形状为 `[3, 20]`，单句输入全为 `0`。
* `attention_mask`：形状为 `[3, 20]`，真实 token 位置为 `1`，`[PAD]` 填充位置为 `0`。

#### 5. 获取 BERT 原生预训练 Embedding 层并推理

```python
pretrained_embedding_layer = bert_model.get_input_embeddings()

with torch.no_grad():
    embeddings = pretrained_embedding_layer(tokenized_inputs["input_ids"])

```

* **`bert_model.get_input_embeddings()`**：取出 BERT 输入部分的词嵌入查找表（`nn.Embedding`，词表大小 $\times$ `768`）。这一层权重来自大规模中文语料预训练，包含了字/词元的基础语义信息。
* **`with torch.no_grad():`**：关闭梯度计算。因为这里只是做特征提取/前向查表，不涉及反向传播更新参数，关闭梯度可显著降低显存/内存占用并加快运行速度。
* **`embeddings` 形状**：`[3, 20, 768]`，含义为 **3 条样本 × 每条 20 个 token × 每个 token 768 维向量**。

最后几行打印清洗前后对比以及张量维度，用于直观确认：

1. 标点和停用词（如“是”、“的”）是否按预期剔除；
2. `input_ids` 是否为 `[3, 20]`、`embeddings` 是否为 `[3, 20, 768]`。

### 三、 补充说明与工程细节

1. **只取 `get_input_embeddings()` vs 完整调用 `bert_model(...)**`：
* `get_input_embeddings()` 仅做**静态词表映射**（同一字在不同上下文中的向量相同，且不包含位置编码和 Transformer 自注意力融合后的上下文语义）。
* 若需要**上下文相关的动态句/字表示**，通常直接调用 `outputs = bert_model(**tokenized_inputs)`，取 `outputs.last_hidden_state`（同样是 `[batch_size, seq_len, 768]`）。


2. **BERT 场景下是否一定要去停用词和标点？**
* 在传统词袋模型（BoW）或 TF-IDF 中，去停用词和标点非常常见；但在 **BERT** 中，标点（如逗号、句号）和虚词往往承载了句法断句与语境信息，微调或做语义编码时有时会**保留**它们，仅在特定清洗需求或关键词统计场景下才去除。


3. **后续模型使用 `[PAD]` 向量时的注意事项**：
* 虽然 `embeddings` 张量中 `[PAD]` 位置也有数值，但在后续池化（Pooling）、求句向量均值或送入下游层时，通常需要结合 `attention_mask` 屏蔽掉 padding 位置，避免无意义的填充向量拉偏结果。
