Cross-Layer Changes in Attention Weights.py代码在提取 `bert-base-uncased` 各层自注意力权重的基础上，补充了**可读 Token 序列还原**、**跨层切片巡检**以及**基于 Seaborn / Matplotlib 的注意力矩阵热力图可视化**，并针对 IDE 绘图后端兼容性做了显式处理。

---

### 一、 逐段代码详细解析

#### 1. 后端指定与依赖导入（第 1–10 行）

* **提前指定 `matplotlib.use('TkAgg')**`：在 `import matplotlib.pyplot as plt` 之前显式切换后端，用于避免部分桌面 IDE / 交互环境下默认后端（如 `backend_interagg`）引发的绘图报错或无响应。若在无图形界面的服务器或想直接保存图片文件而不弹窗，可改用 `'Agg'`（配合 `plt.savefig(...)`）。
* **`seaborn`（`sns`）与 `transformers**`：用于绘制带数值标注的注意力热力图及加载 BERT 分词器与编码器模型。

#### 2. 模型加载、评估模式与 Token 还原（第 12–25 行）

* **`BertModel.from_pretrained("bert-base-uncased", output_attentions=True)`**：直接通过参数开启注意力权重输出；`model.eval()` 关闭 Dropout 等训练期随机算子。
* **`tokens = tokenizer.convert_ids_to_tokens(inputs["input_ids"][0])`**：将 `input_ids` 还原为带 `[CLS]`、`[SEP]` 和词元切分结果的列表，后续热力图横纵轴标签会直接使用它，便于逐词对照。

#### 3. 前向推理与逐层切片巡检（第 27–43 行）

* **`with torch.no_grad():`**：推理与注意力观测不需要梯度，关闭可节省显存与计算时间。
* **`attentions` 逐层遍历**：`bert-base-uncased` 共 12 层，`attentions` 为长度 12 的元组，每层张量形状为 `[1, 12, seq_len, seq_len]`。循环中打印每层形状及第 1 个头（索引 `0`）的 `3x3` 左上角切片，既能确认各层维度一致，又不会把完整矩阵刷满控制台。

#### 4. 注意力热力图绘制与调用（第 46–67 行）

* **`plot_attention_heatmap` 函数**：
* `sns.heatmap(..., annot=True, fmt=".2f", cmap="YlGnBu")`：将二维注意力矩阵渲染为颜色热力图，并在格内标注保留两位小数的权重值。
* `xticklabels=tokens` / `yticklabels=tokens`：将列（Key）与行（Query）对齐到具体 Token，使 `Query`（纵轴，发起关注的词元）指向 `Key`（横轴，被关注的词元）的关系一目了然。
* `plt.tight_layout()` 与 `plt.show()`：自动调整边距避免标签截断，并弹出窗口显示图像。


* **`last_layer_head1 = attentions[11][0, 0].cpu().numpy()`**：索引 `11` 对应第 12 层（最后一层），`[0, 0]` 对应第 0 个样本、第 0 个注意力头（即“第 1 个头”），转为 NumPy 数组后传入绘图函数。

### 三、 实践中的细节与可改进点

1. **序号从 `0` 开始与从 `1` 开始的对照**：
代码中 `attentions[11][0, 0]` 对应的是**第 12 层、第 1 个头**，标题里写了 `Layer 12, Head 1`；若后续切换为其他层或头，记得同步修改 `layer_num` 和 `head_num` 参数，避免图题与实际索引不一致。
2. **序列较长时的可读性**：
当前示例句子较短，格内显示 `annot=True` 很清晰；若换成较长文本或更多注意力头，热力图格子会变密，此时可适当增大 `figsize` 或关闭 `annot=True` 以防数字重叠。
3. **跨层与多头对比扩展**：
单看最后一层第 1 个头只能反映该特定视角的注意力分布；在分析时通常还会循环遍历不同层（如浅层 Layer 1、中层 Layer 6、深层 Layer 12）或同一层的不同头，观察关注模式从局部语法/特殊符号向语义关联演变的差异。
