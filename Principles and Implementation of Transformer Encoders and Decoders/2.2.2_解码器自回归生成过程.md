在 Transformer 架构中，自回归生成（Autoregressive Generation）是指模型在生成文本时，**逐个 Token（字/词）串行输出**的过程。每一个新生成的 Token，都会被拼接在已有文本的末尾，作为下一步输入的上下文。这种“滚雪球”式的生成方式，是 GPT 系列、LLaMA 以及经典 Transformer 解码器的核心工作机制。

下面详细拆解解码器的自回归生成过程，重点区分**训练阶段**与**推理阶段**的不同，并剖析其核心步骤。

---

## 1. 核心概念：什么是自回归？

数学上，给定输入上下文（或编码器的输出）X，生成目标序列 $Y = (y_1, y_2, \dots, y_T)$ 的联合概率可以根据链式法则分解为条件概率的乘积：


$$P(Y\vert{}X) = \prod_{t=1}^{T} P(y_t \mid y_1, y_2, \dots, y_{t-1}, X)$$

这意味着：**第 $t$ 个词 $y_t$ 的生成，只依赖于前面的所有历史词 $(y_1, y_2, \dots, y_{t-1})$ 以及输入上下文 $X$**。这就是“自回归”的含义——用历史预测未来。

---

## 2. 训练阶段 vs. 推理阶段的巨大差异

为了兼顾效率，Transformer 在**训练**和**推理**时采用了截然不同的策略：

### (1) 训练阶段：并行计算（Teacher Forcing）

* **痛点**：如果训练时也像推理那样一个字一个字地串行生成，GPU 无法并行，训练速度会极其缓慢。
* **解法（教师强制）**：在训练时，模型会**一次性接收完整的标准目标序列**作为解码器输入。为了防止解码器“作弊”直接看到后面的答案，Transformer 引入了**因果掩码（Causal Mask / Look-ahead Mask）**。
* **效果**：掩码将注意力权重矩阵中对角线右上方的未来信息置为 $-\infty$，使每个位置只能“看到”自己及之前的历史。这样，GPU 就可以在单次前向传播中并行计算所有位置的损失函数。

### (2) 推理阶段：串行循环（Autoregressive Loop）

* 在实际生成（如对话、写作）时，我们并不知道未来的答案。因此，解码器必须**严格按照时间步，一个接一个地生成 Token**。

---

## 3. 推理阶段的详细步骤（Step-by-Step）

假设我们要让大模型生成一句话，完整的自回归循环如下：

### 步骤 1：输入初始化（Prompt / Start Token）

* **对于 Encoder-Decoder 模型（如原始 Transformer）**：编码器先对源文本 $X$ 进行一次前向传播，输出全局上下文记忆（Memory）。解码器的初始输入通常是一个特殊的起始符 `[SOS]`（Start of Sequence）。
* **对于 Decoder-only 模型（如 GPT）**：初始输入就是用户输入的 Prompt 文本 Token 序列。

### 步骤 2：解码器前向传播（Forward Pass）

将当前的输入序列送入解码器堆栈：

1. **掩码自注意力（Masked Self-Attention）**：由于是推理阶段的最后一步，当前的最后一个 Token 可以看到历史所有的 Token，计算它们之间的关联。
2. **交叉注意力（Cross-Attention，仅 Encoder-Decoder 有）**：解码器层的 Query 与编码器的输出（Key 和 Value）进行交互，让解码器决定当前应该关注编码器文本的哪个部分。
3. **前馈网络与线性投影**：经过多层解码器处理后，最后一个位置的输出向量通过一个线性层（Linear Layer），映射到整个词表大小（Vocabulary Size）的空间，得到每个候选词的 **Logits（未归一化的得分）**。

### 步骤 3：概率分布与 Token 采样（Sampling / Decoding Strategy）

通过 Softmax 函数将 Logits 转化为词表中每个词的概率分布。根据具体的解码策略选择下一个 Token：

* **贪婪搜索（Greedy Search）**：直接选择概率最高的那个 Token。
* **随机采样与温度控制（Sampling with Temperature）**：根据概率分布随机抽取，温度调节概率分布的平缓度。
* **Top-k / Top-p 采样**：截断低概率的词，防止模型生成胡言乱语。

### 步骤 4：状态更新与循环迭代

* 将刚刚生成的崭新 Token 拼接到历史输入序列的末尾。
* **检查终止条件**：如果生成的 Token 是结束符 `[EOS]`（End of Sequence），或者达到了最大生成长度（Max Length），则**终止循环**。
* 否则，将新序列作为下一次循环的输入，**重复步骤 2 ~ 4**。

---

## 4. 核心优化技术：KV Cache（键值缓存）

在自回归生成的循环中，每生成一个新字，都要把之前所有的历史文本重新输入模型算一遍，这会造成巨大的计算冗余（随着序列变长，计算量呈平方级上升）。

* **KV Cache 原理**：在计算自注意力时，历史文本的 Key ($K$) 和 Value ($V$) 矩阵在之前的步骤中已经计算过了。模型会把它们缓存（Cache）在显存中。
* 每生成一个新 Token 时，**只需要计算当前新 Token 的 $Q, K, V$**，并把新算出的 $K$ 和 $V$ 追加到缓存后面，直接与历史 $K, V$ 做矩阵乘法。这极大地加速了自回归生成的推理速度。
