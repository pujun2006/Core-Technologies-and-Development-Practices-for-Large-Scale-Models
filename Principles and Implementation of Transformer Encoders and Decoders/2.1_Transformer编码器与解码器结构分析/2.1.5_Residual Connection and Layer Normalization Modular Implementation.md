Residual Connection and Layer Normalization Modular Implementation.py代码将原本写在 `TransformerEncoderLayer` 内部的残差连接（Residual Connection）**和**层归一化（Layer Normalization）逻辑抽离出来，封装成了一个独立的通用模块——`ResidualNormLayer`。

这种面向对象的设计提升了代码的复用性与可读性。以下是对该代码各个模块的逐层深度拆解：

---

## 一、 `MultiHeadSelfAttention`（多头自注意力模块）

*该模块与之前保持一致，负责“横向”的空间通信与上下文聚合。*

* **核心职责**：通过将输入映射为 $Q, K, V$，利用多头机制并行计算缩放点积注意力，捕获序列中不同词之间的相关性，并通过最终的线性层（`out_proj`）投影输出。

---

## 二、 `ResidualNormLayer`（解耦的残差与归一化模块）

这是本次代码最大的亮点，专门用来实现经典的 **Post-LN（Post-Layer Normalization）** 结构。

```python
class ResidualNormLayer(nn.Module):
    def __init__(self, d_model, dropout=0.1):
        super(ResidualNormLayer, self).__init__()
        self.layer_norm = nn.LayerNorm(d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, sublayer_output):
        x = x + self.dropout(sublayer_output)
        return self.layer_norm(x)

```

1. **残差连接（Residual Connection）**：
* `x + self.dropout(sublayer_output)`：将子层的输出先经过 Dropout 防止过拟合，然后与原始输入 `x`（即上一层的输出）进行逐元素相加。
* **作用**：构建信息高速公路，允许梯度在反向传播时直接绕过子层无损回传，彻底解决了深层神经网络中常见的**梯度消失**问题。


2. **层归一化（Layer Normalization）**：
* `self.layer_norm(x)`：对相加后的特征向量在特征维度（`d_model`）上计算均值和方差进行归一化。
* **作用**：稳定每一层的数值分布，防止因网络加深导致数值过大或过小，加速模型收敛。



---

## 三、 `FeedForward`（前馈网络模块）

* **核心职责**：负责“纵向”的特征深度加工。
* **结构**：由两个线性层组成（`linear1` 负责升维，如从 512 到 2048；`linear2` 负责降维回 512），中间夹着 ReLU 激活函数和 Dropout，对每个位置的特征独立进行非线性变换。

---

## 四、 `TransformerEncoderLayer`（编码器层：优雅的组件拼装）

由于抽离了 `ResidualNormLayer`，编码器层的 `forward` 逻辑变得异常清爽和直观：

```python
def forward(self, src):
    # 1. 多头自注意力子层
    src2 = self.self_attn(src)
    src = self.residual_norm1(src, src2)

    # 2. 前馈网络子层
    src2 = self.feed_forward(src)
    src = self.residual_norm2(src, src2)

    return src

```

* **模块化复用**：`self.residual_norm1` 和 `self.residual_norm2` 分别复用了同一个 `ResidualNormLayer` 模块，分别包裹在自注意力层和前馈网络层之后，完美还原了 Post-LN 编码器层的标准数据流：
