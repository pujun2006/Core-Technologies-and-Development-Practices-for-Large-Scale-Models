Encoding-decoding process.py代码实现了一个符合经典 **Transformer 架构**（基于 Vaswani 等人的论文 *Attention Is All You Need*）的 PyTorch 模型。

整个代码由浅入深，从底层的多头注意力机制（Multi-Head Attention）一直搭建到完整的 **Encoder-Decoder 结构**。

---

### 一、 核心模块详细解析

#### 1. `MultiHeadAttention`（多头注意力机制）

该模块既支持 **Self-Attention（自注意力）**，也支持 **Cross-Attention（交叉注意力）**。

* **参数初始化**：
* `d_model`：模型的隐藏层维度（特征总维度）。
* `num_heads`：注意力头的数量。每个头的维度为 `d_head = d_model // num_heads`。
* `query`, `key`, `value`：分别用于生成 $Q, K, V$ 矩阵的线性层。


* **`forward` 前向传播逻辑**：
1. **区分 Attention 类型**：如果未传入 `key_x` 和 `value_x`，则默认进行 Self-Attention（即 $K$ 和 $V$ 都等于 `query_x`）；如果是 Decoder 中的 Cross-Attention，则 `query_x` 作为 $Q$，外部传进来的 `memory` 作为 $K$ 和 $V$。
2. **线性投影与多头拆分**：通过 `nn.Linear` 映射后，使用 `.view()` 和 `.transpose(1, 2)` 将张量形状从 `[Batch, Seq_Len, d_model]` 转换成 `[Batch, Num_Heads, Seq_Len, d_head]`，从而让多个头可以并行计算。
3. **缩放点积注意力（Scaled Dot-Product Attention）**：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$



代码中通过 `torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_head)` 计算注意力得分，并除以 $\sqrt{d_k}$ 防止数值过大导致梯度消失。
4. **Mask（掩码）机制**：如果传入了 `mask`，则将对应位置的分数设为 `float('-inf')`（负无穷），在经过 `softmax` 后权重趋近于 0。
5. **拼接与输出**：通过 `.transpose(1, 2).contiguous().view(...)` 将多头的结果重新拼接回 `[Batch, Seq_Len, d_model]`，最后通过 `out_proj` 线性层。



#### 2. `FeedForward`（前馈神经网络）

* 包含两个线性层（Linear）和一个激活函数（ReLU）、以及 Dropout。
* 作用是对注意力的输出进行非线性变换，增强模型的表达能力。公式为：

$$\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2$$



#### 3. `ResidualNormLayer`（残差连接与层归一化）

* 实现了 Transformer 中经典的 **Add & Norm** 结构：

$$\text{Output} = \text{LayerNorm}(x + \text{Dropout}(\text{SublayerOutput}))$$


* 残差连接（Residual Connection）能有效解决深层网络中的梯度消失问题，而 LayerNorm 可以加速并稳定训练。

#### 4. `TransformerEncoderLayer`（编码器层）

* 组合了：
1. **自注意力子层** + **残差归一化1**
2. **前馈网络子层** + **残差归一化2**


* 输入 `src` 经过编码器层后，特征得到了全局上下文的融合。

#### 5. `TransformerDecoderLayer`（解码器层）

* 比编码器层多了一个注意力子层，包含三个部分：
1. **Masked Self-Attention**（自注意力）：防止解码器在训练时看到“未来的词”（通过因果掩码 `tgt_mask` 实现）。
2. **Cross-Attention**（交叉注意力）：$Q$ 来自于解码器当前的输入（tgt），而 $K$ 和 $V$ 来自于编码器的输出（memory），从而让解码器能够“关注”编码器捕捉到的输入源语言信息。
3. **Feed-Forward**（前馈网络）。



#### 6. `Transformer`（整体模型）

* 将多个 `EncoderLayer` 和 `DecoderLayer` 通过 `nn.ModuleList` 串联起来。
* **执行流程**：
1. **Encoding 阶段**：输入 `src` 依次通过所有的 Encoder 层，最终输出编码特征向量 `memory`。
2. **Decoding 阶段**：目标序列 `tgt` 和 `memory` 一起输入到 Decoder 层中，最终输出解码后的特征张量。

### 二、 测试运行示例分析

在底部的 `if __name__ == "__main__":` 测试脚本中：

* **超参数设置**：`d_model=64`, `num_heads=4`, `num_layers=2`, `dim_feedforward=128`。
* **输入数据**：
* `src = torch.rand(1, 5, d_model)`：模拟 Batch Size = 1，序列长度为 5，特征维度为 64 的输入。
* `tgt = torch.rand(1, 5, d_model)`：模拟目标序列。


* **Mask（掩码）**：
* `src_mask`：全 1 矩阵，表示编码器中所有位置互相可见。
* `tgt_mask = torch.tril(...)`：下三角矩阵（Causal Mask / 因果掩码），用于在解码器自注意力中屏蔽未来信息。



运行这段代码会在控制台打印出各个 Encoder 层和 Decoder 层的计算过程，并最终输出：
`Final Transformer Output Shape: torch.Size([1, 5, 64])`，这说明张量经过完整的 Transformer 编码和解码后，保持了正确的维度结构。
