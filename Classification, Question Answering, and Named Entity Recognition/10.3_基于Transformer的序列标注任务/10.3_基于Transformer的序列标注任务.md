**基于 Transformer 的序列标注（Sequence Labeling）** 是指：给定输入序列 $X = (x_1, x_2, \dots, x_T)$，利用 Transformer Encoder 提取具有全局上下文感知能力的 token 表征，并为每个位置输出对应的离散标签 $Y = (y_1, y_2, \dots, y_T)$。典型任务包括命名实体识别（NER）、词性标注（POS）、分词（CWS）、槽位填充（Slot Filling）以及信息抽取中的片段定位。

与传统 RNN/BiLSTM 相比，Transformer 凭借自注意力机制（Self-Attention）实现了并行计算和任意距离 token 之间的直接交互，显著缓解了长距离依赖建模中的信息衰减问题。

---

## 一、 核心架构范式

在序列标注场景下，通常使用纯编码器（Encoder-only）或预训练语言模型的编码器部分（如 BERT、RoBERTa、DeBERTa 等），因为每个位置 $t$ 都需要同时融合左侧和右侧的上下文信息。

### 1. 输入表征层（Input Representation）

对于输入序列的每个 token $x_t$，模型构建初始向量表示：

* **Token Embedding**：词或子词（Subword）嵌入向量。
* **Positional Encoding**：位置编码，用于注入序列顺序信息。现代模型常用可学习位置嵌入、相对位置偏置或 **RoPE（旋转位置编码）** 等增强局部与相对距离感知。
* **Segment / Type Embedding**（视模型与任务而定）：区分不同文本段或辅助输入。

### 2. 多层 Transformer Encoder

每一层包含 **Multi-Head Self-Attention** 与 **Feed-Forward Network（FFN）**，配合残差连接与 LayerNorm（Pre-LN 或 Post-LN）：

* **Self-Attention**：计算查询 $Q$、键 $K$、值 $V$ 的缩放点积注意力，使位置 $t$ 的隐状态 $h_t^{(l)}$ 直接聚合整句中相关 token 的语义特征。
* **长距离与结构建模**：部分变体（如 DeBERTa 的解耦相对注意力）将内容与相对位置分开建模，对边界敏感的序列标注任务尤为有效。

### 3. 解码与预测头（Decoding Head）

得到顶层隐状态 $H = (h_1, h_2, \dots, h_T)$ 后，常见解码方式主要有两种：

| 解码方式 | 结构特点 | 优点 | 缺点 / 适用边界 |
| --- | --- | --- | --- |
| **Transformer + Linear / MLP + Softmax** | 每个位置独立映射到标签空间 $P(y_t \mid x)$ | 推理速度快、并行度高、实现简单 | 忽略相邻标签之间的转移约束（如 `I-PER` 直接跟在 `B-LOC` 后） |
| **Transformer + CRF** | 在发射分数之上引入标签转移矩阵 $A$，建模整条标签序列 $P(Y \mid X)$ | 显式学习合法标签转移规则，提升实体边界一致性 | 训练需计算前向配分函数（Log-Sum-Exp），解码使用 Viterbi 算法，带来额外计算开销 |

## 二、 标签体系与子词对齐细节

### 1. 常见标注方案

* **BIO（Inside, Outside, Beginning）**：`B-XXX` 表示实体开始，`I-XXX` 表示实体内部延续，`O` 表示非实体。
* **BIOES / BILOU**：增加 `E`（结尾）和 `S`（单字/单词实体），边界信息更精细，常在实体密集或边界模糊的数据集上表现更稳健。

### 2. 子词分词（Subword Tokenization）与标签对齐

在 BPE / WordPiece 等子词切分下，一个词或汉字组合可能被拆分为多个子词 token（如 `playing` $\rightarrow$ `play`, `##ing`）：

* **对齐策略**：通常只将原始词的标签赋给**第一个子词**，后续子词标记为忽略索引（如 PyTorch `CrossEntropyLoss` 中的 `ignore_index=-100`）或延续 `I-` 标签；推理时再将子词预测还原回原始词/字符级别。
* **中文场景特殊性**：中文预训练模型多以字（Character）为基本单元，天然契合字级序列标注（如字级 NER/CWS），但需注意跨字词语边界与歧义消解。

## 三、 训练目标与损失函数

### 1. Token 级交叉熵损失

当使用独立分类头时，最小化负对数似然：


$$\mathcal{L}_{\text{CE}} = -\sum_{t=1}^{T} \log P(y_t^* \mid x, \theta)$$

### 2. CRF 条件随机场损失

对于整条标签序列 $Y = (y_1, \dots, y_T)$，其打分为发射分数与转移分数之和：


$$s(X, Y) = \sum_{t=1}^{T} \left( E_{t, y_t} + A_{y_{t-1}, y_t} \right)$$


训练目标是最大化真实序列的概率：


$$\log P(Y^* \mid X) = s(X, Y^*) - \log \sum_{\tilde{Y} \in \mathcal{Y}(X)} \exp\big(s(X, \tilde{Y})\big)$$


其中分母通过动态规划（前向算法）高效计算，预测阶段使用 **Viterbi 算法**求最优路径 $\arg\max_{Y} s(X, Y)$。

### 3. 常见训练与优化技巧

* **类别不平衡与长尾问题**：序列标注中 `O` 标签占比极高，特定实体类样本较少；可结合类别权重、Focal Loss 或数据增强，但需注意校准概率阈值避免过度预测导致精确率（Precision）大幅下降。
* **分层学习率与正则化**：预训练编码器通常使用较小学习率（如 `1e-5` ~ `5e-5`），顶部线性层或 CRF 层可使用稍大学习率，并配合 Warmup、权重衰减与 Dropout。

## 四、 评估指标与工程实践要点

### 1. 评估指标

* **Token 级指标**：准确率、精确率、召回率、F1——适合 POS 等逐位置判定的任务。
* **Span / 实体级指标（如 seqeval / CoNLL 评测标准）**：要求**实体类型与起止边界完全一致**才算正确（TP），这是 NER 等跨度任务的金标准，比 Token 级 F1 更严格、更能反映真实抽取效果。

### 2. 常见工程痛点与应对

* **超长文本截断**：超过模型最大上下文长度（如 512）时，直接截断会丢失尾部实体；可采用滑动窗口重叠切分，并在重叠区域通过投票或最大置信度合并结果。
* **领域迁移与少样本**：在医疗、金融、垂直行业中，通用语料与专业术语差异大，通常先做领域增量预训练（DAPT/TAPT），再进行任务微调或结合提示/少样本策略。
* **在线推理延迟**：若对时延要求极高，可通过知识蒸馏、量化、剪枝或 ONNX / TensorRT 导出加速编码器推理。
