Data Selection and Sample Weight Assignment in Incremental Training.py代码实现了一个**基于加权随机采样（`WeightedRandomSampler`）的增量训练示例**：将历史旧数据与新增量数据合并后，通过为新旧样本赋予不同采样权重来调节它们在每个 Epoch 中被抽中的概率，并在 `collate_fn` 中按批次动态 Padding，最后使用 `AdamW` 与梯度裁剪完成多轮训练。

---

## 一、 整体工作流概览

1. **模型与分词器加载**：加载 `bert-base-chinese` 的 3 分类模型（`AutoModelForSequenceClassification`）及对应分词器。
2. **新旧数据拼接与数据集封装**：合并 `old_texts / old_labels`（3 条）与 `new_texts / new_labels`（2 条），通过轻量 `CustomTextDataset` 返回原始文本与标签。
3. **动态 Padding `collate_fn**`：在组 batch 时统一调用 `tokenizer` 进行 `padding=True` 与 `truncation=True`（`max_length=128`），输出 PyTorch 张量。
4. **样本权重与 `WeightedRandomSampler**`：旧样本权重设为 `0.5`、新样本权重设为 `1.0`，启用有放回采样（`replacement=True`），并传入 `DataLoader`（此时不设 `shuffle=True`）。
5. **训练与梯度裁剪循环**：遍历 3 个 Epoch，执行前向计算 Loss、反向传播、`clip_grad_norm_` 梯度裁剪与 `AdamW` 参数更新。

---

## 二、 逐段代码详细解析

### 1. 模型加载与新旧数据合并

```python
model_name = "bert-base-chinese"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(
    model_name, num_labels=3
)

old_texts = ["旧数据样本1", "旧数据样本2", "旧数据样本3"]
new_texts = ["新数据样本1", "新数据样本2"]
old_labels = [0, 1, 0]
new_labels = [1, 2]

texts = old_texts + new_texts
labels = old_labels + new_labels

```

* **数据拼接顺序**：前 `len(old_texts)`（即索引 `0, 1, 2`）为旧数据，后 `len(new_texts)`（索引 `3, 4`）为新数据；后续权重列表正是依据索引位置 `i < len(old_texts)` 进行区分的。

### 2. `CustomTextDataset` 与 `collate_fn` 动态填充

```python
class CustomTextDataset(Dataset):

  def __init__(self, texts, labels):
    self.texts = texts
    self.labels = labels

  def __len__(self):
    return len(self.texts)

  def __getitem__(self, idx):
    return {
        "text": str(self.texts[idx]),
        "labels": self.labels[idx],
    }


def collate_fn(batch):
  batch_texts = [item["text"] for item in batch]
  batch_labels = [item["labels"] for item in batch]

  # 动态 Padding
  inputs = tokenizer(
      batch_texts,
      padding=True,
      truncation=True,
      max_length=128,
      return_tensors="pt",
  )
  inputs["labels"] = torch.tensor(batch_labels, dtype=torch.long)
  return inputs

```

* **职责拆分**：`Dataset` 仅负责按索引返回单条样本字典，不做定长填充；`collate_fn` 在拼成一个 batch 后，按**当前 batch 内最长句子的实际长度**自动 Padding（上限 `128`），减少无效 `[PAD]` 计算。
* **标签类型**：`dtype=torch.long` 满足 `CrossEntropyLoss` 对分类整数标签的类型要求。

### 3. 权重分配与 `WeightedRandomSampler`

```python
# 5. 权重设置（新数据权重 1.0，旧数据权重 0.5）
weights = [0.5 if i < len(old_texts) else 1.0 for i in range(len(labels))]

# 实例化 WeightedRandomSampler
# replacement=True 意味着采样是放回抽样，权重高的样本在单个 Epoch 中可能被多次抽到
sampler = WeightedRandomSampler(
    weights=weights, num_samples=len(weights), replacement=True
)

# 6. 创建 DataLoader（注意：有了 sampler，不能设置 shuffle=True）
dataloader = DataLoader(
    dataset, sampler=sampler, batch_size=2, collate_fn=collate_fn
)

```

* **采样概率机制**：`WeightedRandomSampler` 会根据 `weights` 归一化后的相对比例抽取样本。此处每条新样本权重（`1.0`）是每条旧样本权重（`0.5`）的 `2` 倍，因此单次抽样中选中某条新样本的概率是选中某条旧样本的 `2` 倍；单 Epoch 共抽取 `num_samples=len(weights)`（即 `5`）个样本。
* **为什么 `replacement=True` 且不能传 `shuffle=True`？**
* 启用 `replacement=True`（有放回抽样）后，高权重样本才有可能在同一个 Epoch 内被重复抽到，从而提升其在当轮训练中的出现频次。
* 在 PyTorch `DataLoader` 中，`sampler` 与 `shuffle=True` 互斥（传入自定义 `sampler` 时必须保持 `shuffle=False` 或不传 `shuffle`），否则会直接抛出 `ValueError`。



### 4. 训练循环与梯度裁剪

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
model.to(device)
optimizer = AdamW(model.parameters(), lr=2e-5)

num_epochs = 3
for epoch in range(num_epochs):
  model.train()
  total_loss = 0.0
  for batch in dataloader:
    input_ids = batch["input_ids"].to(device)
    attention_mask = batch["attention_mask"].to(device)
    batch_labels = batch["labels"].to(device)

    optimizer.zero_grad()
    outputs = model(
        input_ids=input_ids, attention_mask=attention_mask, labels=batch_labels
    )
    loss = outputs.loss
    loss.backward()

    # 梯度裁剪防爆炸
    torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
    optimizer.step()

    total_loss += loss.item()

  avg_loss = total_loss / len(dataloader)
  print(f"第 {epoch+1} 轮平均损失: {avg_loss:.4f}")

```

* **全参数更新与梯度裁剪**：当前代码未冻结模型层，因此 `AdamW` 会更新全部参数；在 `loss.backward()` 之后、`optimizer.step()` 之前调用 `clip_grad_norm_(model.parameters(), max_norm=1.0)`，可将全局梯度范数上限控制在 `1.0`，降低增量阶段分布变化带来的梯度尖峰风险。

## 四、 工程实践中的潜在注意点

1. **采样加权与损失加权的区别**
* `WeightedRandomSampler` 改变的是**哪些样本被抽进 batch、被抽中多少次**（属于数据采样层面的调整）；
* 样本级 Loss 加权（先算逐样本 loss 再乘权重）改变的是**单次前向中每条样本对梯度的贡献幅度**。两者可单独使用，也可按需组合，但要注意避免把权重设得过于极端导致某类样本过度重复或旧数据回放不足。


2. **旧数据规模远大于新数据时的配比控制**
实际增量训练中，历史旧数据往往远多于新增量数据。若直接按 `len(weights)` 抽样且旧数据总量庞大，即使旧样本单条权重较低，总量也可能淹没新数据；此时常会结合**历史回放子集抽样**或按目标新旧比例调整权重，并在独立的历史基准集与新数据验证集上分别评估。
3. **小数据集与尾批统计**
当前演示共 5 条样本、`batch_size=2`，每个 Epoch 会迭代 `3` 个 batch（最后一个 batch 只有 1 条样本），`total_loss / len(dataloader)` 是按 batch 数量做简单平均；在真实数据量较大时，通常可按样本数加权统计平均 loss，并配合验证集 checkpoint 保存。
