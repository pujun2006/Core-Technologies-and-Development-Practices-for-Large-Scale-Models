Generation and visualization of the attention matrix.py这段代码在前面自注意力实现的基础上，新增了**注意力权重矩阵返回**以及**多头注意力热力图可视化（`visualize_attention_matrix`）**，方便直观观察各个注意力头对不同位置的关注分布。

下面按模块说明其结构、关键改动与实现细节。

## 二、 `MultiHeadAttention` 模块改动点

与前一段代码相比，核心计算流程一致，但有两个关键变化：

1. **无 `mask` 参数**：`forward(self, x)` 仅接收输入 `x`（形状 `[batch_size, seq_len, d_model]`），执行的是未掩码的全序列自注意力（`scores` 经 `F.softmax(scores, dim=-1)` 直接得到 `[B, num_heads, seq_len, seq_len]` 的权重矩阵）。
2. **返回双值 `(attention_weights, output)**`：
* `attention_weights`：形状为 `[batch_size, num_heads, seq_len, seq_len]`，每一行在 `Key` 维度上之和为 `1.0`（概率分布）。
* `output`：形状为 `[batch_size, seq_len, d_model]`，是多头加权求和、拼接并经过 `self.out_proj` 后的最终特征输出。

## 三、 注意力矩阵可视化函数（`visualize_attention_matrix`）

```python
def visualize_attention_matrix(attention_matrix):
    num_heads = attention_matrix.size(1)
    fig, axes = plt.subplots(1, num_heads, figsize=(16, 4), sharey=True)
    fig.suptitle("多头注意力矩阵可视化", fontsize=14, fontweight="bold")

```

* **子图布局**：按注意力头数量 `num_heads` 创建 `1` 行 `num_heads` 列的并排子图（`figsize=(16, 4)`），并设置 `sharey=True` 共享 Y 轴刻度。
* **张量转 NumPy**：
```python
matrix = attention_matrix[0, i].detach().cpu().numpy()

```


* 取第 `0` 个样本（`batch_idx = 0`）、第 `i` 个头的二维注意力矩阵，形状为 `(seq_len, seq_len)`。
* 调用 `.detach()` 脱离计算图，`.cpu()` 移至主机内存（若在 GPU 上运行尤为必要），再转为 `numpy` 数组供 `seaborn` 绘图。


* **热力图参数**：
* `cmap="viridis"` 使用 perceptually uniform 色图；
* `square=True` 保证每个注意力格子为正方形；
* `annot=True` 与 `fmt=".2f"` 在格内标注保留两位小数的注意力权重；
* `vmin=0.0, vmax=1.0` 固定色标范围为 `[0, 1]`，便于跨头横向对比权重强弱；
* 仅在首个子图（`i == 0`）标注 `"Query 位置"`，其余子图共享 Y 轴以保持版面紧凑；`plt.tight_layout()` 自动调整间距后通过 `plt.show()` 弹出窗口。

**实际使用时的注意点**：

1. **随机初始化权重下的分布特点**：由于模型权重未经过训练，各个头的热力图会呈现相对均匀或轻微随机波动的分布，无法反映真实语义/句法分工；通常需在训练后或加载已训练权重时观察才有解释意义。
2. **序列长度与 `annot=True` 的适配性**：当 `seq_len` 较大（例如超过 12~16）或 `num_heads` 较多时，开启 `annot=True` 会导致单元格内数字拥挤甚至重叠，且单行子图宽度受限，此时通常会关闭数字标注（`annot=False`）或改用多行网格布局。
