Normalization of attention weights and application of the Softmax function.py代码实现了带 **Softmax 归一化**的缩放点积注意力机制（Scaled Dot-Product Attention），并在单条模拟序列上完成了前向计算与结果打印。与前一段代码相比，它调整了测试张量的维度规模（序列长度为 4、特征维度为 16），并将无穷小掩码填充值统一为 `float("-inf")`。

下面按核心函数、测试流程与张量维度变化三个部分进行详细说明：

---

## 一、 核心函数：`attention_with_softmax`

该函数封装了注意力得分计算、掩码过滤、Softmax 归一化及特征聚合四个完整步骤：

### 1. 缩放点积计算

```python
d_k = query.size(-1)
scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(d_k)
print("原始点积得分矩阵:\n", scores)

```

* `query.size(-1)` 提取特征维度 $d_k$（此处为 `16`）。
* `key.transpose(-2, -1)` 将 `key` 的最后两个维度互换，使矩阵乘法维度对齐。
* 除以 `math.sqrt(d_k)` 完成缩放，防止高维点积数值过大导致后续 Softmax 梯度消失。

### 2. 掩码过滤（Masking）

```python
if mask is not None:
    scores = scores.masked_fill(mask == 0, float("-inf"))

```

* 当传入 `mask` 时，凡是 `mask == 0` 的位置都会被填入 `-inf`。
* 在经过指数运算 $e^x$ 时，$e^{-\infty} = 0$，从而确保被屏蔽位置在加权求和时权重严格为 `0`。

### 3. Softmax 归一化

```python
attention_weights = F.softmax(scores, dim=-1)
print("归一化后的注意力权重矩阵:\n", attention_weights)

```

* `dim=-1` 表示沿最后一个维度（即每个 Query 对应的所有 Key 维度）做 Softmax。
* 归一化后，每个 Query 对应的权重向量非负且和为 `1`，直观体现注意力分配比例。

### 4. 加权求和输出

```python
attention_output = torch.matmul(attention_weights, value)
return attention_output, attention_weights

```

* 将 `attention_weights` 与 `value` 相乘，按权重融合各位置信息，返回最终输出张量 `attention_output` 与权重矩阵 `attention_weights`。

---

## 二、 测试函数：`test_attention_with_softmax`

```python
def test_attention_with_softmax():
    batch_size = 1
    seq_len = 4
    d_k = 16

    query = torch.rand(batch_size, seq_len, d_k)
    key = torch.rand(batch_size, seq_len, d_k)
    value = torch.rand(batch_size, seq_len, d_k)

    attention_output, attention_weights = attention_with_softmax(
        query, key, value
    )
    print("最终的注意力输出:\n", attention_output)
    print("归一化后的注意力权重:\n", attention_weights)

```

* 构造 `batch_size=1`、`seq_len=4`、`d_k=16` 的均匀分布随机张量 `torch.rand`（取值区间为 `[0, 1)`）。
* 未传入 `mask` 参数，因此所有位置均参与注意力计算。
* 分别打印缩放后的得分矩阵、Softmax 归一化后的权重矩阵以及最终的注意力输出。

---

## 三、 张量形状变化轨迹

在 `test_attention_with_softmax()` 运行过程中，各关键张量的形状演变如下：

1. **输入张量**：`query`、`key`、`value` 均为 `(1, 4, 16)`。
2. **转置后的 Key**：`key.transpose(-2, -1)` 形状为 `(1, 16, 4)`。
3. **缩放得分矩阵 `scores**`：形状为 `(1, 4, 4)`，对应 4 个 Query 对 4 个 Key 的相似度得分。
4. **注意力权重 `attention_weights**`：形状仍为 `(1, 4, 4)`，且最后一维各元素之和为 `1`。
5. **注意力输出 `attention_output**`：形状为 `(1, 4, 16)`，与输入 `query` 保持一致，便于后续残差连接（Residual Connection）与层归一化（LayerNorm）。
