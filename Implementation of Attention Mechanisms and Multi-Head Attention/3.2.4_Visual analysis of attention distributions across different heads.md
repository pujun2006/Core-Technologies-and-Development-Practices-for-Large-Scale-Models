Visual analysis of attention distributions across different heads.py代码聚焦于**多头注意力权重分布的计算与多头热力图可视化**，用于对比不同注意力头在同一个输入序列上产生的注意力模式。

与前一段代码相比，它的核心变化是：**简化了 `MultiHeadAttention`（仅保留 $Q、K$ 投影与注意力矩阵计算，去掉了加权求和、拼接、输出投影及 `out_proj`），直接返回 `attention_weights**`，并将序列长度扩大到 `8`，热力图配色改为 `"coolwarm"` 且去掉了单元格内的数字标注。

下面按模块说明其实现细节与关键点。

## 二、 `MultiHeadAttention` 模块逻辑

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        ...
        self.query = nn.Linear(d_model, d_model)
        self.key = nn.Linear(d_model, d_model)
        self.value = nn.Linear(d_model, d_model)

```

1. **初始化与校验**：断言 `d_model % num_heads == 0`，计算单头维度 `self.d_head = d_model // num_heads`（测试中 `64 // 4 = 16`），并创建 `query`、`key`、`value` 三个线性层。
2. **多头投影与重排**：
* `Q`、`K`、`V` 经线性映射后，通过 `.view(batch_size, seq_len, self.num_heads, self.d_head).transpose(1, 2)` 变换为 `[batch_size, num_heads, seq_len, d_head]`。
* 这一步将各头拆分为独立并行维度，使后续矩阵乘法可以同时处理所有头。


3. **缩放点积与归一化**：
```python
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_head)
attention_weights = F.softmax(scores, dim=-1)
return attention_weights

```


* 计算 `Q` 与 `K` 转置的批量点积，除以 $\sqrt{d_{\text{head}}}$ 控制方差缩放，再沿最后一维（`Key` 维度）做 `softmax` 得到归一化的注意力权重矩阵，形状为 `[batch_size, num_heads, seq_len, seq_len]`。
* **注意**：这里虽然定义了 `self.value` 并在 `forward` 中计算了 `V`，但并未参与后续加权求和或输出映射，因为该模块仅用于提取和观察注意力分布矩阵。

## 三、 多头注意力分布可视化（`visualize_attention_heads`）

```python
def visualize_attention_heads(attention_matrix):
    num_heads = attention_matrix.size(1)
    fig, axes = plt.subplots(1, num_heads, figsize=(16, 4.5), sharey=True)
    fig.suptitle("不同头的注意力分布可视化", fontsize=14, fontweight="bold")

```

* **并排子图**：根据注意力头数 `num_heads` 生成 `1` 行 `num_heads` 列的子图（`figsize=(16, 4.5)`），`sharey=True` 使所有子图共享纵轴（`Query位置`）。
* **热力图绘制**：
```python
sns.heatmap(
    attention_matrix[0, i].detach().cpu().numpy(),
    cmap="coolwarm",
    cbar=True,
    ax=ax,
    square=True,
    vmin=0.0,
    vmax=1.0,
)

```


* 取第 `0` 个样本、第 `i` 个头的二维矩阵（`8 × 8`），经 `.detach().cpu().numpy()` 转换为 NumPy 数组。
* `cmap="coolwarm"` 采用蓝-白-红发散色图；由于注意力权重本身非负且位于 `[0, 1]`，固定 `vmin=0.0, vmax=1.0` 可让不同头之间保持统一色阶刻度。
* 未设置 `annot=True`，因此在序列长度增加到 `8` 时画面更清爽，不会被密集数字遮挡。
