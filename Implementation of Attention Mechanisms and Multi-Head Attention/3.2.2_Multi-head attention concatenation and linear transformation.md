Multi-head attention concatenation and linear transformation.py代码实现了一个**自注意力（Self-Attention）版本的 `MultiHeadAttention` 模块**，重点在于展示了多头拼接（第 4 步）**与**输出线性变换（第 5 步）的张量形状流转与调试打印。

相比前一段支持可选 `key_x`、`value_x` 的版本，这段代码将 `forward` 签名简化为 `(self, x, mask=None)`，即 `Q`、`K`、`V` 全部由同一个输入张量 `x` 线性映射而来，并在拼接与输出映射后增加了形状打印日志。

---

## 一、 模块初始化（`__init__`）

```python
assert d_model % num_heads == 0, f"d_model ({d_model}) 必须能被 num_heads ({num_heads}) 整除"
self.num_heads = num_heads
self.d_head = d_model // num_heads
self.d_model = d_model

self.query = nn.Linear(d_model, d_model)
self.key = nn.Linear(d_model, d_model)
self.value = nn.Linear(d_model, d_model)
self.out_proj = nn.Linear(d_model, d_model)

```

* **维度拆分参数**：通过断言保证 `d_model` 可被 `num_heads` 整除，从而得到单头特征维度 `d_head = d_model // num_heads`。
* **四组全连接层**：`query`、`key`、`value` 负责将输入特征映射到多头子空间拼接维度（`num_heads * d_head == d_model`）；`out_proj` 负责在拼接后进行跨头线性融合与输出映射。

---

## 二、 前向传播与形状变化（`forward`）

设输入 `x` 的形状为 `[batch_size, seq_len, d_model]`（测试中为 `[1, 5, 64]`，即 `num_heads = 8`、`d_head = 8`）。

### 1. 输入线性映射

```python
Q = self.query(x)  # [batch_size, seq_len, d_model]
K = self.key(x)
V = self.value(x)

```

三个线性层并行作用于 `x`，输出形状均为 `[1, 5, 64]`。

### 2. 多头重塑与维度转置

```python
Q = Q.view(batch_size, seq_len, self.num_heads, self.d_head).transpose(1, 2)

```

* `view(B, seq_len, num_heads, d_head)` 将最后一维 `64` 拆分为 `8` 个头 × 每头 `8` 维，形状变为 `[1, 5, 8, 8]`。
* `transpose(1, 2)` 交换序列长度维（第 1 维）与注意力头维（第 2 维），变为 `[1, 8, 5, 8]`。
* `K` 与 `V` 执行相同变换，将 `(batch_size, num_heads)` 置于前两维，以便后续按头批量执行矩阵乘法。

### 3. 缩放点积注意力与掩码

```python
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_head)

if mask is not None:
    scores = scores.masked_fill(mask == False, float("-inf"))

attention_weights = torch.nn.functional.softmax(scores, dim=-1)
attention_output = torch.matmul(attention_weights, V)

```

* `K.transpose(-2, -1)` 形状为 `[1, 8, 8, 5]`，`Q` 与之相乘得到 `scores`，形状为 `[1, 8, 5, 5]`，再除以 $\sqrt{8}$ 缩放方差。
* 若传入 `mask`，将 `mask == False` 的位置填充为 `"-inf"`，经过 `softmax(dim=-1)` 后权重归零（采用“True 保留、False 屏蔽”的约定）。
* `attention_weights`（`[1, 8, 5, 5]`）左乘 `V`（`[1, 8, 5, 8]`），得到各头加权后的上下文表示 `attention_output`，形状为 `[1, 8, 5, 8]`。

### 4. 多头拼接（Concatenation）

```python
attention_output = (
    attention_output.transpose(1, 2)
    .contiguous()
    .view(batch_size, seq_len, d_model)
)
print("多头拼接后的输出形状:", attention_output.shape)

```

* `transpose(1, 2)` 把维度从 `[1, 8, 5, 8]` 换回 `[1, 5, 8, 8]`，让同一序列位置下各个头的向量在相邻维度排列。
* `.contiguous()` 将转置后可能非连续的内存重新排列为连续块，随后 `.view(batch_size, seq_len, d_model)` 将 `8 * 8` 合并为 `64`，输出形状为 `[1, 5, 64]`。
* 此刻各头的特征只是在特征维度上并排拼接，尚未做跨头混合。

### 5. 输出线性变换

```python
output = self.out_proj(attention_output)
print("线性变换后的最终输出形状:", output.shape)
return output

```

* `self.out_proj` 对 `[1, 5, 64]` 的拼接向量执行线性变换 $H_{\text{concat}} W^O + b^O$，输出形状仍为 `[1, 5, 64]`。
* 这一步让不同注意力头捕获的信息发生线性组合，并使输出维度与残差连接及后续层对齐。
