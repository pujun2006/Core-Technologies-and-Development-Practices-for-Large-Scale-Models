Weight Extraction and Interpretation.py代码将**完整的多头注意力计算（含 `mask` 与 `out_proj`）**与**文本终端下的注意力权重逐头提取打印**结合在了一起，适合在命令行或日志输出中直接检查每个头的权重矩阵数值。

下面按模块说明其结构、改动点与实现细节。

---

## 一、 `MultiHeadAttention` 模块：完整前向与权重返回

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        ...
        self.query = nn.Linear(d_model, d_model)
        self.key = nn.Linear(d_model, d_model)
        self.value = nn.Linear(d_model, d_model)
        self.out_proj = nn.Linear(d_model, d_model)

```

与之前偏重可视化的简化版相比，这里恢复了完整的标准结构：

1. **支持可选掩码（`mask=None`）**：
```python
if mask is not None:
    scores = scores.masked_fill(mask == False, float("-inf"))
attention_weights = F.softmax(scores, dim=-1)

```


当传入 `mask` 时，将 `mask == False` 的位置填充为 `"-inf"`，随后沿最后一个维度（`Key` 维度）执行 `softmax`，使被屏蔽位置的权重归零，其余位置构成和为 `1` 的概率分布。
2. **完成加权聚合、多头拼接与输出映射**：
```python
attention_output = torch.matmul(attention_weights, V)
attention_output = (
    attention_output.transpose(1, 2)
    .contiguous()
    .view(batch_size, seq_len, self.d_model)
)
output = self.out_proj(attention_output)
return attention_weights, output

```


既保留了正常前向计算所需的 `output`（形状 `[batch_size, seq_len, d_model]`），又将 `attention_weights`（形状 `[batch_size, num_heads, seq_len, seq_len]`）一并返回，方便后续提取分析。

## 二、 注意力权重提取与格式化打印（`extract_attention_weights`）

```python
def extract_attention_weights(attention_weights):
    num_heads = attention_weights.size(1)

    for i in range(num_heads):
        print(f"\n--- Head {i+1} 的注意力权重矩阵 ---")
        # 使用 torch.set_printoptions 精简打印保留 4 位小数
        torch.set_printoptions(precision=4, sci_mode=False)
        print(attention_weights[0, i].detach())

```

* **逐头切片提取**：通过 `attention_weights[0, i]` 取出第 `0` 个样本、第 `i` 个注意力头的二维张量，形状为 `[seq_len, seq_len]`（测试中为 `6 × 6`）。矩阵中第 `r` 行、第 `c` 列的数值表示第 `r` 个 `Query` 位置对第 `c` 个 `Key` 位置的注意力权重。
* **`.detach()` 分离计算图**：在打印或后续做数值统计时切断梯度追踪，避免误持计算图引用。
* **打印精度与格式控制**：`torch.set_printoptions(precision=4, sci_mode=False)` 将浮点显示精度设为 4 位小数并禁用科学计数法（如 `0.0001` 而不是 `1e-04`），使终端矩阵对齐更直观，便于人工核对每行权重之和是否接近 `1.0000` 以及掩码位置是否生效。

## 三、 测试函数与使用细节

```python
def test_attention_weights_extraction():
    batch_size = 1
    seq_len = 6
    d_model = 64
    num_heads = 4
    ...

```

* **运行输出**：先打印 `所有头的注意力权重矩阵形状: torch.Size([1, 4, 6, 6])`，随后依次输出 `Head 1` 至 `Head 4` 共 4 个 `6 × 6` 的权重矩阵。
* **细节与扩展建议**：
1. **`set_printoptions` 的全局作用域**：`torch.set_printoptions(...)` 修改的是全局张量打印配置；若后续代码希望恢复默认打印格式，可在打印后重新调用 `torch.set_printoptions(profile="default")`。
2. **结合 `mask` 验证**：当前测试未传入 `mask`，若传入下三角因果掩码（`torch.tril(torch.ones(seq_len, seq_len, dtype=torch.bool))`），可直观看到打印矩阵右上角全部变为 `0.0000`。
3. **量化分析扩展**：当 `seq_len` 变长时，逐矩阵肉眼查看效率较低，通常会在 `extract_attention_weights` 基础上进一步计算每行的最大权重位置（`argmax`）、分布熵或各头之间的关注差异。
