Multi-head grouping and parallel computing strategy.py代码实现了一个**可复用的多头注意力（Multi-Head Attention）PyTorch 模块**，同时支持自注意力（Self-Attention）和交叉注意力（Cross-Attention），并内置了基础的注意力掩码（Mask）逻辑。

下面按模块拆解其结构、张量形状变化、实现细节以及潜在边界问题。

---

## 一、 模块初始化（`__init__`）

```python
assert d_model % num_heads == 0, ...
self.num_heads = num_heads
self.d_head = d_model // num_heads
self.d_model = d_model

```

* **整除校验**：确保总隐藏维度 `d_model` 能够均分给 `num_heads` 个注意力头，避免后续 `view` 切分维度时出错。
* **单头维度计算**：`d_head = d_model // num_heads`（示例测试中 `64 // 8 = 8`）。
* **四个线性投影层**：
* `self.query`、`self.key`、`self.value`：形状均为 `nn.Linear(d_model, d_model)`，将输入特征映射到多头拼接空间（`num_heads * d_head`）。
* `self.out_proj`：将拼接后的多头特征再映射回 `d_model`，实现不同注意力头之间的信息融合。



---

## 二、 前向传播流程（`forward`）

假设输入形状为：

* `query_x`：`[batch_size, seq_len_q, d_model]`
* `key_x`、`value_x`：`[batch_size, seq_len_k, d_model]`（若传 `None`，则自动回退为 `query_x`，即标准自注意力）

### 1. 线性映射

```python
Q = self.query(query_x)  # [B, L_q, d_model]
K = self.key(key_x)      # [B, L_k, d_model]
V = self.value(value_x)  # [B, L_k, d_model]

```

这一步完成所有头所需的 $Q、K、V$ 线性变换，形状仍保持 `[batch_size, seq_len, d_model]`。

### 2. 拆头与维度转置

```python
Q = Q.view(batch_size, seq_len_q, self.num_heads, self.d_head).transpose(1, 2)

```

* `view(B, L, num_heads, d_head)`：把最后一维 `d_model` 拆成 `(num_heads, d_head)`。
* `transpose(1, 2)`：将维度从 `[B, L, H, D]` 交换为 `[B, H, L, D]`。
* **原因**：后续 `torch.matmul` 默认在最后两个维度 `[L, D]` 上做矩阵乘法，将 `num_heads` 提到序列维前面后，`(B, H)` 会作为批处理维度并行计算各个注意力头。`K` 和 `V` 同理（序列长度为 `seq_len_k`）。

### 3. 缩放点积注意力与 Mask

```python
scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_head)

```

* `K.transpose(-2, -1)` 将 `[B, H, L_k, D]` 变为 `[B, H, D, L_k]`。
* `torch.matmul(Q, ...)` 得到注意力得分矩阵 `scores`，形状为 `[B, H, L_q, L_k]`。
* 除以 `math.sqrt(self.d_head)` 用于缩放点积方差，防止维度较大时 `softmax` 梯度消失。

接着处理掩码：

```python
if mask is not None:
    scores = scores.masked_fill(mask == False, float("-inf"))

```

* 这里采用的是“True 表示保留、False 表示屏蔽”的布尔掩码约定（`mask == False` 的位置填入 `-inf`）。
* 经过 `softmax(dim=-1)` 后，`-inf` 对应的注意力权重会变为 `0`。

最后计算加权值：

```python
attention_weights = torch.nn.functional.softmax(scores, dim=-1)
attention_output = torch.matmul(attention_weights, V)

```

* `attention_weights` 形状为 `[B, H, L_q, L_k]`，`V` 形状为 `[B, H, L_k, D]`。
* 相乘后 `attention_output` 形状为 `[B, H, L_q, D]`。

### 4. 多头拼接与输出投影

```python
attention_output = (
    attention_output.transpose(1, 2)
    .contiguous()
    .view(batch_size, seq_len_q, self.d_model)
)
return self.out_proj(attention_output)

```

* `transpose(1, 2)` 恢复为 `[B, L_q, H, D]`。
* `.contiguous()` 确保张量在内存中连续存储（因为 `transpose` 只改 stride 不改内存排布，直接 `view` 会报错）。
* `.view(B, L_q, self.d_model)` 将 `H * D` 合并回 `d_model`。
* `self.out_proj(...)` 输出最终结果 `[B, L_q, d_model]`。

## 五、 实际使用时的关键注意事项

1. **`mask` 的形状与广播规则**：
* `scores` 的形状是 `[batch_size, num_heads, seq_len_q, seq_len_k]`。
* 传入的 `mask` 需要能广播到该形状（例如 `[batch_size, 1, 1, seq_len_k]` 用于 Padding Mask，或 `[1, 1, seq_len_q, seq_len_k]` 用于 Causal Mask）。如果维度不兼容，`masked_fill` 会直接报错。


2. **整行全被 Mask 的数值边界**：
* 若某一行所有位置 `mask` 都为 `False`，整行 `scores` 全为 `-inf`，`softmax` 可能产生 `NaN`（在交叉注意力或极端 padding 场景下需留意）。


3. **训练与推理扩展点**：
* 这份实现是基础教学/原型版本，不包含注意力 `Dropout`、推理阶段的 `KV Cache` 复用，也未接入 `F.scaled_dot_product_attention`（FlashAttention 等底层优化内核）或 GQA 分组映射；若用于长序列训练或大模型推理，通常会在这些环节做进一步封装。
